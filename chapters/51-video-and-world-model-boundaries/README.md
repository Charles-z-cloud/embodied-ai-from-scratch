## 看起来像未来，不等于能回答行动后果

**视频生成**像根据开头画面或说明续写后面的画面，是生成具有时间顺序的图像序列。它可以是世界建模的一部分，但是否能用于控制，要看有没有正确接收动作、保留状态并预测相关后果。本章不按模型名字判断能力，而按证据逐项判断。

你已经会第32章图文条件、第44—45章生成、第47—50章预测和决策，因此现在可以明确区分这些问题，不必靠“很像真实世界”这种模糊描述。

## 1. 一段视频怎样成为模型输入

视频可表示为(T,H,W,C)，批量时再加B。T是帧数；帧率决定每帧间隔，12帧不一定代表12秒。时空模型可以将每帧切块后加入空间和时间位置，也可以先压缩为潜在表示再生成。若各帧独立生成，即使单帧漂亮，也可能出现物体身份、位置或光照不一致。

**时序一致性**像同一个人物不会无故换衣服或瞬移，是跨时间的属性与关系保持合理。**物理合理性**要求运动、接触等符合所声称任务的约束。前者与后者不同：一段持续匀速穿墙的视频可以很平滑，却不符合该场景的碰撞规则。

## 2. 两种条件分布不是一回事

只看过去画面的预测可写：

$$p(o_{t+1:t+H}\mid o_{\le t}).$$

可用于动作比较的预测通常需要：

$$p(o_{t+1:t+H}\mid o_{\le t},a_{t:t+H-1}).$$

后一种输入包含明确的候选动作序列，并且动作坐标、单位、频率必须可解释。模型输入有一个名为action的字段也不够，要实际交换动作检验输出是否按正确方向变化。

不同目标需要不同输出：控制器可能只需目标相对位置、接触事件或奖励，无须生成所有像素；内容创作可能主要关注画面质量。不能把某类模型在一个用途的表现自动转移到另一个用途。

## 3. 一个可枚举的反例

假设训练记录中物体总是以0.5米/秒向右走，周期0.2秒。一个忽略动作、永远预测“向右0.1米”的模型，在这样的观察数据上能预测准确，也可生成平滑合理的右移动画。

现在保持同一初始状态，分别施加向左和向右命令。真正系统两种后果应相差0.2米；忽略动作的模型输出相同，无法用于选择方向。这个失败与画面是否清晰无关。

```bash
python chapters/51-video-and-world-model-boundaries/examples/action_counterexample.py
```

脚本构造100个初始位置，在只向右观察分布和左右配对干预条件下比较两个手写预测器。一个忽略动作，一个使用已知动作更新。它不是训练新视频模型，而是证明“观察分布预测好”不足以推出“动作后果预测正确”的最小反例。

## 4. 可直接使用的评测协议

| 检验 | 保持不变 | 主动变化 | 指标 |
|---|---|---|---|
| 动作敏感性 | 同一历史与起点 | 左/右、开/合等动作 | 方向、位移差、接触变化 |
| 时间尺度 | 动作单位与初态 | 频率或持续时间 | 实际位移与速度一致性 |
| 遮挡记忆 | 真实运动规则 | 遮挡长度 | 重现位置、身份误差 |
| 长时预测 | 同一初态和动作序列 | 展开长度 | 状态误差随时域曲线 |
| 决策价值 | 同一任务和预算 | 有无预测模型 | 真实闭环成功率 |

动作敏感不是越敏感越好。如果动作尚未发生作用、或接触约束限制运动，未来变化应符合系统规律。评测还要有“不该变化的量”，例如只移动物体不应改变其颜色。

在每个对照中固定生成随机种子或使用多次配对抽样，减少采样差异的干扰；随机模型应比较输出分布而非强求每次样本一模一样。报告样本数、失败例及覆盖范围，避免只挑几段视频。

## 5. 从相关性到因果解释需要什么

**相关性**像看到雨天常有雨伞，是观察到变量共同变化；**干预**像主动改变一个条件再观察后果，是人为设置某个变量以区别可能机制。行为数据里的动作由策略选择，可能与未观测状态相关。直接拟合数据分布中的 $p(s'\mid s,a)$，不自动证明任意更换行为策略后仍可作正确因果预测。

完整状态、充分动作覆盖、可控实验、正确同步和环境假设有助于判断。若只观测到成功推门动作，不能凭模型生成的合理画面断言它已经理解所有门轴、锁扣和接触条件。反事实评测要在实际可检验、定义清楚的范围内进行。

## 6. 读模型介绍时的五个问题

先查输入是否有历史和动作；再查输出是图像、状态、奖励还是动作；接着看训练数据由谁如何采集；然后核对评测是否包含动作变化和真实闭环；最后确认作者结论与自己的运行证据分别是什么。

[World Models](https://worldmodels.github.io/)和[PlaNet](https://arxiv.org/abs/1811.04551)是将预测与控制联系起来的经典例子，但本章不据此给所有视频生成模型贴相同标签。[检查记录](validation.md)只对应自编反例。

过关要求：可以解释一个模型在哪些意义上建模了世界、还缺哪些控制证据；能设计同初态不同动作的对照；不会把“画面合理”“物理预测准确”“可以改善控制”当成同一个结论。下面进入VLA，将视觉语言信息转成可执行动作。
