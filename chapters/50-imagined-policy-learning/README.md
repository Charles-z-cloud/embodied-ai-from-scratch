## 预测器还可以用来产生学习经验

第49章每次行动都搜索候选。**想象训练**像在脑中练习许多回合，再把学到的技能带到实际任务，是用世界模型生成轨迹并据此更新策略的方法。部署时策略可直接输出动作，不必每次重新做CEM搜索。

**Dreamer**是一条把潜在世界模型与想象中的行为学习结合的研究路线。典型循环是：真实交互数据 → 更新世界模型 → 从真实历史推断内部状态 → 先验想象未来 → 更新actor和critic → 用新策略收集真实数据。不同版本的分布、目标与稳定训练技巧有差异，不能把所有版本混成一个固定公式。

## 1. 哪些参数由哪些损失更新

世界模型用真实序列的观测、奖励、终止等预测目标训练；actor用想象轨迹中的行为目标训练；critic拟合未来回报。训练actor时若允许模型权重也随“让回报更高”而改变，模型可能把未来改得越来越美好而不再对应数据。

因此需要区分：**冻结参数**是禁止优化器修改模型权重；**停止计算梯度**是切断某条运算路径。对连续可微动作，可能需要经过固定模型对动作求导，才能更新actor。此时模型参数设 `requires_grad_(False)`，但不能把整个想象循环包在 `torch.no_grad()` 中。

也可使用第40章的采样log概率梯度，不要求对动作转移求导。具体Dreamer实现会根据动作类型和版本使用不同估计方式。本章选连续可微教学路径。

## 2. 继续概率与lambda return

**继续概率**像估计“这一步之后任务是否还继续”，是模型对非终止事件的预测c_t。它与奖励不同；达到目标可能奖励高但继续概率低。时间上限是否视为终止仍依第39章约定。

critic不能只看短想象窗口的奖励，否则会忽略窗口之后的未来。**lambda return**像在“一步奖励加价值估计”和“多走几步再估计”之间做加权，是组合不同长度自举目标的一种方式：

$$G_t^\lambda=\hat r_t+\gamma c_t\left[(1-\lambda)V(\hat s_{t+1})+\lambda G_{t+1}^\lambda\right],\qquad G_H^\lambda=V(\hat s_H).$$

λ∈[0,1]，γ为折扣。λ=0只用一步加价值，λ=1沿窗口累积直到末端价值；并非消除所有模型偏差。critic可拟合停止梯度的该目标；actor的具体目标和梯度处理取决于所选算法。

手算：γ=0.9、c=1、r=1、下一价值2、下一lambda回报4、λ=0.5，本步为1+0.9×(1+2)=3.7。若c=0，结果为1。

## 3. 离散潜变量的梯度近似

第43章高斯重参数化适合连续潜变量。若内部状态用离散类别抽样，直接argmax或类别采样一般不可微。**直通估计（straight-through）**像前向使用硬选择，反向暂借一个平滑近似的梯度，是一种有偏梯度估计。常见写法为 `hard + soft - soft.detach()`：数值上等于hard，反向梯度来自soft。

这不是离散采样的精确导数。训练为何可行要依具体目标和实验支持；本章模型是连续确定性转移，不需要该技巧，也未实现完整离散RSSM。

## 4. 我们实际实现的简化版

读取第47章学习的二维动力学并冻结权重。actor输入当前位置与目标，网络4→64→64→2，tanh输出乘0.5，符合速度范围。用环境种子0—79产生真实起点作为训练起点集合；之后actor优化只使用模型预测，不拿专家动作作标签。

每批64起点，展开15步，最小化各步距离平方加0.01动作平方的平均，Adam0.003、500次更新、种子7。它是有限窗口可微模型策略优化，没有critic、学习奖励头、继续概率头或lambda训练；前文用于读懂Dreamer整体，不能把这个小程序称为完整Dreamer复现。

训练目标与第42章类似，是已知目标几何的代价，并非原环境回报原样照搬。模型固定但actor通过模型的输入导数获得梯度。程序检查世界模型权重训练前后完全一致、第一步actor梯度确实非零。

```bash
python chapters/47-learned-dynamics/examples/dynamics.py
python chapters/50-imagined-policy-learning/examples/imagination.py
```

在种子200—219的20个测试起点，分别于学习模型和真实环境中闭环运行初始actor及训练后actor。报告成功率、平均回报与步数；测试每次根据各自当前状态出动作，最大100步。它与15步训练窗口不同，这个差异公开记录。

## 5. 想象高分，现实可能低分

actor可能利用模型未准确覆盖的动作，长想象会累积误差；模型重构真实数据很好也不保证新策略访问的状态准确。真实数据收集、模型更新和策略训练需要循环，而不是永远对初始模型做梦。训练起点也应尽量来自有真实数据支持的状态。

[检查记录](validation.md)区分想象与真实表现。若二者都很好，只能说明本简单环境中可迁移，不能推出任意世界模型中训练都可靠。若想象高而真实低，先检查动作反归一化、预测分布偏移和终止处理，而不是把模型评分当最终答案。

原始思想见[Dreamer论文](https://arxiv.org/abs/1912.01603)，后续代表见[DreamerV3论文](https://arxiv.org/abs/2301.04104)及[作者仓库](https://github.com/danijar/dreamerv3)。作者项目使用独立的JAX技术栈；这里没有安装、运行或声称复现其150多任务实验。选学时固定代码版本，在独立环境从小任务开始。

过关要求：清楚区分模型预测、每步规划和想象训练策略；为每组参数指出更新目标；说明冻结权重与保留输入梯度可以同时成立；能计算lambda return；坚持用真实环境任务指标验证想象收益。下一章讨论视频生成与可用于决策的世界模型之间的界限。
