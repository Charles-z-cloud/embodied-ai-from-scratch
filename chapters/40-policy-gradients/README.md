## 为什么可以直接学习动作概率

第39章先估计每个动作的价值，再选最大者。**策略梯度**像直接调整“下一次更愿意选哪条路”的旋钮，是对参数化策略的期望回报求梯度并更新参数的方法。**随机策略**输出动作分布 $\pi_\theta(a\mid s)$；离散动作可用第16章softmax，连续动作可用第12章高斯分布。

本章先用有限回合、γ=1推导，避免把不同折扣约定混在一起。用τ表示整条轨迹，R(τ)为该轨迹奖励总和，目标 $J(\theta)=\mathbb E_{\tau\sim p_\theta}[R(\tau)]$。优化时做梯度上升；如果调用最小化损失的优化器，则加负号。

## 1. 从概率求导到REINFORCE

假设环境初始分布和转移不依赖策略参数θ，轨迹概率为初始概率、每步策略概率和环境转移概率的乘积。利用 $\nabla p=p\nabla\log p$：

$$\nabla J=\sum_\tau \nabla p_\theta(\tau)R(\tau)
=\mathbb E\left[R(\tau)\sum_t\nabla\log\pi_\theta(a_t\mid s_t)\right].$$

这一步不要求能对环境求导，因为环境概率在对θ求导时是常量。直觉是：让带来较好回报的已选动作以后更可能发生。**REINFORCE**就是用采样轨迹回报构造这种梯度估计的一类基础算法。

某动作不能改变它发生之前已收到的奖励，可把总回报换成从当前时刻开始的回报 $G_t$，减少无关噪声。实际最小化代理损失：

$$L_{policy}=-\frac1B\sum_{i=1}^B\sum_t\log\pi_\theta(a_t^{(i)}\mid s_t^{(i)})\;\mathrm{stopgrad}(G_t^{(i)}).$$

B是回合数，本章按回合平均，并非除有效动作数。**stopgrad/detach**像把分数当作已经写好的评语，不让网络反过来改动评语本身；准确地说，是阻断该分支的梯度。回报通过外部环境计算时本来没有梯度，使用神经价值估计时仍需注意。

若优化从起点计算的折扣目标 $\sum_t\gamma^t r_t$，严格推导的reward-to-go形式还涉及外层γᵗ权重或相应折扣状态分布约定。不要把γ=1的教学代码无说明改成任意γ，随后宣称公式完全相同。

## 2. 基线为什么可以减

**基线**像先扣除“这个路口通常能得几分”，只关注比预期好多少；数学上可从G_t中减去不依赖当前采样动作的b(s_t)：

$$\mathbb E_{a\sim\pi}[b(s)\nabla\log\pi(a\mid s)]
=b(s)\nabla\sum_a\pi(a\mid s)=0.$$

因此在满足条件时不改变期望梯度，但可能减少方差。它与“比较算法基线”是同一个词的不同用途。随意使用依赖当前动作的基线，通常不能直接用这条等式保证无偏。

**方差**表示估计在不同采样之间的波动。回报大不意味着梯度一定大：还取决于减去基线后的差、概率对参数的敏感度等。策略已几乎确定时，某些log概率的梯度可能很小。

## 3. Actor、Critic和优势

**Actor**像负责选动作的驾驶员，即策略网络；**Critic**像估计当前局面前景的评估员，即价值网络。**优势函数**表示一个动作比该状态下通常的选择好多少：$A^\pi(s,a)=Q^\pi(s,a)-V^\pi(s)$。

**Actor–Critic**结合两者。用TD构造一种简单优势估计：

$$\hat A_t=r_t+\gamma(1-d_t)V_\phi(s_{t+1})-V_\phi(s_t).$$

actor用 $-\log\pi_\theta(a_t\mid s_t)\,\mathrm{detach}(\hat A_t)$ 更新；critic回归到停止梯度的TD目标。这个估计在critic不精确时可能有偏，通常比整回合回报的方差更小，但不是必然。多步优势估计是进一步组合不同预测长度的办法，本章不要求先掌握完整GAE实现。

连续动作可用 $a\sim\mathcal N(\mu_\theta(s),\operatorname{diag}(\sigma_\theta(s)^2))$，log概率在动作维求和。若把高斯样本用tanh压到有限范围，概率密度还需要变量变换修正；简单裁剪后直接把裁剪值代入原高斯密度并不等价。本章不实现连续高斯策略，等动作生成章节再扩展。

## 4. PPO裁剪的是概率比率

**PPO**像限制一次修改不能过度依赖旧试卷上的几个好答案，是用旧策略采样数据、通过受限制的代理目标更新策略的方法。一个常见形式为：

$$\rho_t(\theta)=\frac{\pi_\theta(a_t\mid s_t)}{\pi_{old}(a_t\mid s_t)},\quad
J_{clip}=\mathbb E[\min(\rho_t\hat A_t,\operatorname{clip}(\rho_t,1-\epsilon,1+\epsilon)\hat A_t)].$$

ρ是新旧动作概率比，ε是裁剪幅度，不是ε-greedy探索概率。旧log概率和优势在这一批更新中固定。优势为正且ρ超过上界时不再奖励继续放大；优势为负时要小心乘负数后大小关系改变。

这是目标函数中的限制，不是严格把所有状态的新旧概率差锁在一个范围，更不是安全保证。采样分布改变太大仍会出问题。原始方法见[PPO论文](https://arxiv.org/abs/1707.06347)，基础推导参考[策略优化教学](https://spinningup.openai.com/en/latest/spinningup/rl_intro3.html)。本章实际运行的是REINFORCE，未声称实现完整PPO。

## 5. 多种子走廊实验

5格走廊，起点2、左端0失败、右端4成功，最多8步；普通步奖励-0.01，进入右端奖励+1，左端-1。时间上限是这个有限任务的真实截止，时刻t和位置都作为输入，避免遗漏剩余时间。策略是40×2可学习logit表，相当于给每个时刻位置一组softmax参数。

```bash
python chapters/40-policy-gradients/examples/reinforce.py
```

每次收集32回合，按真实轨迹计算回报，不使用最优动作标签。Adam0.08、150次更新；训练种子7/8/9，各用独立的同一评测种子101运行1000回合。报告初始均匀策略、训练后的随机策略成功率和平均回报，不仅展示最好种子。代码用活跃掩码排除已结束回合的后续虚拟步，损失按32回合平均。

[检查记录](validation.md)报告结果。本任务极简单、始终向右即可成功；它验证的是采样、log概率、回报和梯度的连接，不代表复杂机器人操控。过关要求：能解释为什么环境不可微也能训练；区分actor、critic、优势；知道PPO旧策略数据的用途；区分这里的奖励学习与下一章使用专家动作的模仿学习。
