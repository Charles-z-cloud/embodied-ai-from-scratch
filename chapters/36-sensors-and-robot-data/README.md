## 机器人看到的不是完整世界

第35章直接读取精确位置和速度，真实系统通常只能读取传感器。**传感器**像机器人的眼睛和触觉，是把物理量转成可记录信号的设备。**本体感知**像闭眼仍能感觉手肘弯了多少，指关节角、速度等机器人自身状态的测量，与观察外部物体不同。

RGB图像记录颜色，深度图给每个像素一个距离相关值，关节编码器测量关节运动，力传感器测量作用力。深度值可能表示沿相机光轴的Z，也可能表示到相机的射线距离，二者不能混用。无效深度常有特殊值，0不应自动解释成物体就在相机中心。

## 1. 从三维点投影到像素

**针孔相机模型**像光线穿过一个小孔落在屏幕上，是用透视几何描述三维到二维成像的简化。先用第33章变换把世界点送到相机系：$p^C=R_{CW}p^W+t_{CW}$。本章相机系x向右、y向下、z向前，点为(X,Y,Z)，Z>0。

**内参**像相机自己的尺子，描述焦距和像素中心等成像参数；**外参**像相机在世界地图里的位置与朝向，描述参考系之间的刚体变换。无畸变、无轴倾斜的投影为：

$$u=f_xX/Z+c_x,\qquad v=f_yY/Z+c_y,\qquad
K=\begin{bmatrix}f_x&0&c_x\\0&f_y&c_y\\0&0&1\end{bmatrix}.$$

u、v是像素横纵位置；fx、fy以像素为单位；cx、cy为主点。三维坐标需统一长度单位，但X/Z会抵消长度单位。Z≤0的点不能按普通前方可见点处理；投影落在图像外也不表示可见。

例如fx=fy=100，主点(32,24)，点(0.2,0.1,2)米投影到(42,29)像素。若深度Z=2米已知，可反算X=(u−cx)Z/fx、Y=(v−cy)Z/fy；没有深度时一个像素对应一条射线，不能唯一确定三维点。

**标定**像先用已知尺子校准相机，是通过已知几何与观测估计内参、外参或畸变参数的过程。**畸变**是实际镜头让直线等结构偏离理想针孔投影的现象。公式只覆盖简化模型；本章不假装已经标定真实相机。若裁剪图像，主点需减去裁剪偏移；若按比例缩放，还需同步调整焦距和主点。更多约定见[OpenCV相机标定官方文档](https://docs.opencv.org/4.13.0/d9/d0c/group__calib3d.html)。本实验不用安装OpenCV。

## 2. 时间戳比数组行号重要

**时间戳**像每张照片背面的拍摄时间，是记录事件发生或到达时刻的数值。相机30Hz、关节100Hz时，两份记录第10行不对应同一时刻。曝光时间、设备生成时间、主机收到时间也可能不同；设备时钟有偏移时，应先映射到共同时间基准。

**时间对齐**是为一次决策挑选对应时刻的数据。本章演示“截至该时刻最新可得”的关节样本：选 $t_j\le t_{camera}$ 中最大的j，并检查数据年龄 $t_{camera}-t_j$ 不超过阈值。没有更早样本、时间倒序或数据过旧时明确报错，不偷偷使用未来样本。

离线分析可以在两侧时间点之间插值，但在线决策不能读取尚未来到的右侧样本。还要考虑接收延迟：仅比较采样时间不足以证明数据当时已到达。我们的合成实验假定采集后立即可用，真实日志需要额外记录接收时间。

位置误差可能只是时间错位。例如物体速度0.5米/秒，错位0.1秒就有约0.05米差异。此时更大的神经网络不能修复错误的配对含义。

## 3. 动作字段必须带说明书

**动作约定（schema）**像说明每一列到底装什么，是关于字段形状、单位、参考系、时间和含义的明确规则。一个合格记录至少包括：

| 字段 | 本章示例约定 |
|---|---|
| observation_time | 秒，共同时钟，采样时刻 |
| joint_position | (n,)，转动关节弧度，关节顺序固定 |
| camera_rgb | (H,W,3)，uint8，RGB而非BGR |
| action | 下一控制周期的目标位置增量，米，基座系 |
| action_time | 命令应用时刻，不能只给文件写入时间 |
| gripper | 0=张开、1=闭合，明确是命令还是测量 |

对于同一固定坐标系中的位置，绝对目标a_abs与增量δ满足 $a_{abs}=p_{current}+\delta$。若增量定义在工具系，需先转到基座系；三维朝向更不能直接把旋转矩阵逐元素相加。连续角度还要考虑跨越±π的表示问题。

测量得到的 $p_{t+1}-p_t$ 是实际位移，不必等于发出的命令增量。动力学、限幅、控制误差会造成差异。学习数据要注明用的是指令还是实际运动结果，不能交换标签。

## 4. 归一化与恢复单位

**归一化**像将不同量程的尺子改成模型容易使用的刻度，是对数值尺度做约定变换。标准化 $z=(a-\mu)/\sigma$，恢复 $a=\sigma z+\mu$。μ、σ只从训练数据统计，每个动作维度独立；常量维度需设置合理尺度下界，统计值和字段顺序必须随模型保存。

归一化不自动消除动作含义差异。一个数据集记录米，一个记录毫米，即使都变成均值0方差1，也不保证能无条件合并；速度和位置增量的转换还依赖Δt。
