## 先修与目标

先确认你会第22章的图像形状、第23章的卷积、第27章的Transformer和第29章的冻结与微调。本章解决一个接口问题：Transformer接收一串向量，图片却是一张像素网格，怎样连接起来？

## 1. 把图片剪成小方片

**图像块（patch）**像把一张拼图按规则切成小块；准确地说，是从图像空间网格取出的一个局部像素区域。本章使用不重叠的P×P块。H×W、C通道图像在H、W可被P整除时有：

$$N=(H/P)(W/P),\qquad D_{patch}=P^2C.$$

N是块数，每块展平后含 $D_{patch}$ 个数。16×16 RGB图像、P=4，得到16个长度48的向量。线性层把每块投影到d=24维：

$$z_i=W_p\,\mathrm{flatten}(patch_i)+b_p+e_i.$$

$W_p\in\mathbb R^{24\times48}$，$b_p$是偏置，$e_i$是第i个块的位置向量。批量B张图片从(B,3,16,16)变为(B,16,48)，再变为(B,16,24)。**视觉token**就是送进序列模型的一项视觉表示，不一定是一个整数ID。这里没有文字词表查表这一步。

代码用 `unfold` 提取块：先沿高度、宽度切分，再 `permute` 把块编号放在前面、通道和块内像素放在后面，最后reshape。只reshape原图而不调整维度顺序，通常会把不相邻像素拼成错误的块。建议用0到255编号的灰度图检查第一块是否确实是左上角4×4。

## 2. 视觉注意力为什么不用因果掩码

完整图像已经全部可见。判断左上角物体时允许参考右下角，因此普通ViT编码器让每个块关注所有块。本章不能原封不动使用第27章的因果掩码；使用双向的Transformer encoder layer，内部仍有注意力、残差、LayerNorm和FFN。

**位置编码**告诉模型“这一块在什么位置”。没有它时，自注意力对块顺序具有相应的置换性质，平均池化后的分类器不能区分单纯打乱块位置的图像。块内部像素仍保留顺序，不等于网络完全看不到局部几何。本章使用16×24的可学习位置表。

**分类token（CLS）**像额外安排一个收集各块信息的记录员，是加入序列并通过注意力学习全图表示的向量。另一办法是对输出块向量求平均：

$$g=\frac1N\sum_{i=1}^N h_i,\qquad logits=W_cg+b_c.$$

本实验采用平均池化，不引入CLS。两者都需要训练，不是加一个CLS名字就自动得到优质全图特征。

## 3. CNN和ViT各带来什么假设

**归纳偏置**像解题前默认哪些规律更可能成立；准确地说，是结构、数据表示或训练方式对可学习函数的偏好。卷积使用局部连接和共享滤波器，先建模邻近像素；ViT用全局注意力灵活建立块间联系，但仍含切块、位置表示等结构假设。

不能把“Transformer更先进”作为小数据任务一定获胜的理由。数据量、增强、预训练、模型容量和预算都会改变结果。本章只比较两种指定小模型在固定数据和优化协议中的表现。

**数据增强**像在保持答案正确的前提下，换一种画法出题，是对训练输入做保标签变换。横线和竖线任务中，90度旋转会改变标签，不能当作不改标签的增强。本实验通过生成时的位置、亮度与噪声变化提供多样性，没有额外增强。

## 4. 分辨率和代价

P固定，图像宽高同时翻倍，N增至4倍，注意力分数矩阵的元素数 $N^2$ 增至16倍。注意力乘法的主要量级约为 $N^2d$，投影与FFN还有其他成本，所以不能把16倍直接称为整模型运行时间倍率。

改分辨率后，可学习位置表长度也要处理。插值位置表是常用适配办法，但需要讲清二维块网格和CLS等特殊位置，本章固定分辨率不实现它。P变小增加细节和序列长度；P太大可能让小物体细节难以保留。

## 5. 自己训练一个小ViT

```bash
python chapters/30-vision-transformer/examples/compare_vision.py
```

数据为16×16 RGB横线/竖线，独立生成训练512张、验证128张、测试128张；种子分别100/101/102，随机位置、亮度和背景噪声。ViT的块宽4、d=24、4头、FFN48、1层、无Dropout；CNN为两个3×3卷积和平均池化。两者交叉熵、Adam0.003、批32、400步，每50步验证选模，初始化种子7，抽批种子11。

同样更新次数和样本顺序是控制条件；参数量、每步运算量并不相同，因此这是固定训练协议比较，不能宣称“严格等算力”。程序报告参数量、测试准确率与本机耗时，耗时只用于资源记录，不是通用速度排名。基线固定猜训练集多数类，不能用测试标签决定多数类。

读代码顺序：数据生成 → `patchify` → ViT前向 → CNN → 共同训练循环 → 验证选模 → 测试。测试结果和限制见[检查记录](validation.md)。先手工跟踪一张图的维度，再考虑迁移到真实图片。

## 经典来源与过关

[ViT原论文](https://arxiv.org/abs/2010.11929)提出直接将图像块序列交给Transformer进行视觉学习的代表架构；大规模预训练结果不能直接移植为本章小数据保证。API参数参考[PyTorch TransformerEncoderLayer](https://docs.pytorch.org/docs/2.14/generated/torch.nn.TransformerEncoderLayer.html)，本章明确设置 `batch_first=True`、`norm_first=True`、`dropout=0.0`。

过关要求：不看答案算出块数；解释为什么没有文本ID却有视觉token；找到代码中去掉因果限制的位置；区分模型容量、训练样本量和训练步数。下一章将视觉向量和文本向量放进同一个相似度空间。
