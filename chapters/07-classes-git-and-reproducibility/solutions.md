# 第 07 章参考答案与思路

## 练习1

类描述一类对象，实例是具体对象，属性保存状态，方法执行操作。第一个有1条时第二个应为0条，实例各自初始化列表。

## 练习2

类上的同一个列表可能被实例共享。对于实例自己的可变记录，应在__init__中创建。

## 练习3

False和True，因为判断使用严格大于。可调用只说明支持括号调用，不说明存在训练或学习。

## 练习4

diff比较工作区与暂存区，diff --staged比较暂存区与上次提交。add后再修改，会同时有“已暂存但未提交的部分”和“后来修改但尚未暂存的部分”。提交只保存暂存内容。

## 练习5

`git restore --staged 文件名`。不要与会覆盖未暂存工作修改的 `git restore 文件名` 混淆。

## 练习6

不能保证。至少还要有数据及划分、配置、依赖版本、设备、运行命令和结果记录。不同库和硬件可能还有额外不确定性；种子只控制相应生成器的一部分行为。
