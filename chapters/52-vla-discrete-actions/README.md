## 现在把视觉、语言和行动接起来

**视觉语言动作模型（VLA）**像先看桌面、听懂“去红色目标”，再给出移动命令的助手；准确地说，是以视觉、语言及可能的机器人状态为条件，输出动作或动作分布的模型。它是策略的一种组织方式，不是仅在名字里包含三个字母的固定架构。

VLM通常用于视觉语言理解或回答；VLA需要动作表示、示范监督、控制接口和闭环评测。世界模型预测动作后果，VLA选择动作；二者可以组合，也可以各自独立使用。VLA不一定内部包含世界模型，文字回答能力也不自动变成可靠操控能力。

## 1. 输入到执行的完整路径

图像 → 视觉编码；指令 → 词元化与文字表示；机器人状态 → 数值预处理；三者融合 → 动作预测 → 动作解码和恢复单位 → 下层执行 → 新观测。

机器人状态可能包括关节角或末端位置，用第36章的单位与参考系约定。视觉和语言特征可来自预训练VLM，但接入动作需要额外训练。某些架构不使用本体状态，不能把本章输入字段说成全部VLA的强制标准。

## 2. 连续动作怎样变成token

**动作离散化**像把连续油门刻成有限档位，是把连续动作映射到有限编号。对归一化标量u∈[-1,1]，K个等宽箱、宽度Δ=2/K，可令：

$$b=\operatorname{clip}\left(\left\lfloor\frac{u+1}{\Delta}\right\rfloor,0,K-1\right),\qquad \hat u=-1+(b+\tfrac12)\Delta.$$

b是箱号，解码取箱中心。区间内量化误差不超过Δ/2，饱和或错误归一化会带来额外误差。多维动作可以每维一个token，也可以把有限联合动作编码为一个token；联合类别数量随维数指数增长。

本实验为便于手算，使用两维各三档[-0.5,0,0.5]米/秒的**最近档位量化**，联合9类。它与上面的等宽箱中心例子约定不同，代码明确用最近档位，不套错解码。类别k=3i+j，对应横向档i、纵向档j。

离散动作可用交叉熵训练。若逐维自回归，目标为 $-\sum_d\log p(a_d\mid I,l,s,a_{<d})$；本章一次预测9类，因此只有一次分类损失。类别ID不是物理位移，必须解码成速度再由环境乘Δt。

## 3. OpenVLA如何阅读

[OpenVLA论文](https://arxiv.org/abs/2406.09246)与[官方仓库](https://github.com/openvla/openvla)是代表案例。先找视觉语言初始化、机器人数据处理、动作token化和推理返回值，再看微调方式；特别核对动作反归一化使用的是哪份数据统计。

论文原始模型与仓库后续扩展可能不同。阅读时固定论文版本和代码commit，不把后续连续动作扩展混写成原始离散动作设计。本章没有下载其大权重、运行机器人基准或复现其规模训练。

**VLM初始化**提供视觉语言表征和语义先验；动作微调把观测指令与示范动作连接起来。动作标签mask与第29章答案mask思想相通，但动作单位、频率和序列含义必须额外约定。LoRA可减少可训练参数，不保证小显存就足以运行任意模型。

## 4. 教学任务先限制能力范围

桌面中有红、蓝两个目标，绿色移动点由机器人控制。指令只有“去红色目标”和“去蓝色目标”，以两个专用ID表示，不能理解自由中文。位置范围[-1,1]米，周期0.1秒，动作速度各维[-0.5,0.5]，距指定目标<0.09米成功，最多100步。

图像是16×16 RGB高斯亮斑。为了把重点放在接口和动作学习，视觉编码器采用**固定颜色质心**：对红、蓝通道分别以亮度加权平均像素坐标，得到两个二维位置。它确实从图像计算，不读取隐藏目标状态；但依赖理想颜色通道和已知俯视坐标，不是通用学习视觉模型。黑图返回零坐标。绿色通道用于展示，策略另从本体状态读取自身位置。

视觉4维、自身位置2维、指令嵌入4维，融合MLP10→64→64→9。没有使用预训练VLM权重；这是展示VLA数据流的受限模块化策略。第32章已学过可学习视觉语言连接，这里不把手工感知说成大模型语义迁移。

## 5. 整回合划分与未见组合

训练160回合、验证20回合，按回合种子划分。训练排除“指令为红且红目标在右上象限”“指令为蓝且蓝目标在左下象限”两种组合；这些颜色和空间区域各自仍在其他样本出现。测试各40个已见组合的新场景和40个被排除组合。

数据生成采用按目标条件拒绝采样，因此测试明确改变的是指令颜色与目标位置组合。训练可见的另一颜色物体可能处在这些象限，这是设计的一部分。它不代表训练从未见过该区域的像素。

示范教师用真实目标位置做位置反馈，再量化为9类，策略输入只含图像提取特征、指令和自身位置。Adam0.003、1000次更新、批128、种子7，每100步验证选模；分别报告离线动作分类准确率和真实闭环成功率。
