## 从预测成绩走向任务成绩

第47章模型能够预测位置，第42章规划器能够搜索动作。本章只替换规划器的转移函数，观察真实环境的任务表现。**基于模型的决策**像先在心中试走再选择行动，是利用环境模型辅助动作选择或策略学习的方式；模型可为已知公式，也可从数据学习。

本章用完整位置状态规划，不在第48章潜空间中规划。潜空间版本的基本流程类似，但还要正确维护后验状态、使用先验想象、预测奖励，不能把两个输入接口无说明拼在一起。

## 1. 规划器的数据流

给当前位置p和目标g，采样动作序列A，重复 $\hat p_{k+1}=f_\theta(\hat p_k,a_k)$。累计与第42章相同的距离及动作代价，CEM选择最优序列，只执行第一步。真实环境返回下一观测后，以真实位置重新开始预测。

规划内部不能访问候选动作的真实未来状态，也不能把真实环境step调用当成免费模型查询。本章真实公式只用于“已知模型基线”，学习模型分支每一步确实调用保存的神经网络。两者共享代价、动作界限、采样数、精英数和热启动规则。

## 2. 为什么模型误差会被搜索放大

**模型利用漏洞（model exploitation）**像学生发现模拟考试的错误评分规则，专挑能拿虚假高分的答案；在这里是规划器找到模型错误地预测为有利、真实却不利的动作。随机测试动作上的平均误差低，并不保证搜索器会使用的极端动作也准确。

例如训练只见过小推力，模型把大推力错误预测成“瞬间到目标且没有碰撞”，规划器就可能反复选择大推力。更多候选搜索不一定修复问题，反而更容易找到错误模型里的高分漏洞。这个例子是机制说明，不能未经实测就声称本章发生了这种失败。

因此除任务成功率，还要记录实际执行动作有多少超出训练范围，以及在策略访问状态上的一步预测误差。后者只覆盖执行的首动作，不代表未执行候选的全部预测都准确。

## 3. 时域选择是两种误差的取舍

短H看不远，可能错过绕路和长期收益；长H会累计更多模型误差，而且动作序列维度更高、固定候选数的搜索更难。假设每步2维，H从3变20，搜索变量从6个变40个；不能把性能变化全部归因于世界模型误差。

本章H=3、10、20，每次仍三轮×128候选。为了判断模型贡献，必须对每个H同时跑真实公式和学习模型。如果两者随H一起变差，可能主要是搜索预算或目标设计；若只有学习模型变差，才更支持模型误差的解释，但仍需进一步对照。

## 4. 多模型分歧与保守规划

**模型集成（ensemble）**像让几位独立做过题的同学预测同一结果，是训练多个模型并结合输出的方法。若M个模型在同一(s,a)上预测均值为 $\bar s'$，可用：

$$U(s,a)=\frac1M\sum_{m=1}^M\|f_m(s,a)-\bar s'\|^2$$

衡量分歧。**保守规划**是对可能不可靠的预测增加惩罚，例如 $J_{robust}=J+\lambda\sum_kU(\hat s_k,a_k)$。λ需要与单位和任务尺度匹配。

分歧不是经过保证的错误概率。多个模型可能由于相同偏见一起预测错误；数据内高随机性也不一定表现为参数模型分歧。集成、限制动作范围、缩短时域、增加数据都可能有帮助，但不能未经实验把其中任何一个当万能修复。本章未训练集成，先完成单模型与真实模型对照。

## 5. 实际对照

```bash
python chapters/47-learned-dynamics/examples/dynamics.py
python chapters/49-planning-with-world-models/examples/learned_mpc.py
```

读取第47章固定权重，不在规划测试中继续训练。20个初始条件为200—219，动作范围[-0.5,0.5]，模型训练仅见[-0.3,0.3]。每个H对比两种模型；另对H=10加入第41章同样的位置扰动。

记录成功率、平均步数、实际执行的越训练范围动作比例、学习模型对已执行动作的一步MSE。即使已知模型规划器执行动作，也用学习模型做旁路预测诊断；该旁路不参与它的动作选择。

[检查记录](validation.md)保留结果。所有算法仍以真实环境成功判据为准，漂亮预测轨迹不能代替任务结果。过关要求：能指出哪一行完成模型替换；解释观测纠正与自由预测的区别；能设计时域和模型两因素对照；知道模型的训练分布与规划访问分布未必一致。

下一章改变模型的用途：不在每次决策时搜索大量动作，而是在想象轨迹中训练一个以后能直接行动的策略。
