# 第 28 章参考答案与思路

[正文](README.md) · [练习](exercises.md) · [全书目录](../../README.md)

1. 同句的相邻窗口高度重叠，随机分窗口会把近乎相同内容泄漏到不同集合，不能评估新句子。
2. 4个目标：拿、红、块、EOS。预测块之前的序列是BOS、拿、红，最后2个为拿、红。
3. 有效末位置只能注意自己及更早位置，PAD在它之后。左填充把PAD放到过去，需要额外屏蔽或不同处理，不能直接套用本实现。
4. 语料划分、词表与词元化、目标位置与EOS规则、归一化分母、允许输出集合，以及参数选择是否只用验证集。
5. 不能。语料小且局部规则强，固定预算与单个种子不能支持普遍结论。需要确实依赖长距离信息的任务与更多受控实验。
6. 模型从未收到图像、物理状态或动作反馈，只见文字模板；流畅续写不能证明它知道当前红块的位置，更不能证明执行成功。
7. 推理需要匹配结构、词表、预处理和权重；精确继续训练还需优化器、调度器、步数、随机状态和数据迭代进度等。
