# 毕业项目验收清单

[正文](README.md) · [实际结果](results.md)

- [ ] 能独立说明图像、指令、状态和动作各自的形状与单位。
- [ ] 能从空的输出目录按顺序生成四个检查点，并解释哪些步骤训练、哪些只评测。
- [ ] 能区分手写目标选择与学习指令条件。
- [ ] 能说明世界模型预测什么、规划器如何使用预测。
- [ ] 成功率分组报告，包含样本数、失败和时间成本。
- [ ] 消融的变量、未控制差异和预期现象写清楚。
- [ ] 没有把简化任务称为原论文或真实硬件复现。
- [ ] 能说明为什么当前任务无需历史、遮挡任务可能需要历史。
- [ ] 至少完整分析一个失败案例，并给出下一轮区分原因的实验。
- [ ] 能不看代码手算一步速度命令对应的位置变化。
