## 数据不只是一个大数组

**机器人本体（embodiment）**像不同身体能做不同动作，指机器人结构、关节、传感器、执行器及其与环境交互的配置。**跨本体学习**是在不同机器人之间共享或迁移能力；同样长度的动作向量不代表物理含义相同。

回顾第36章数据字段、第41章轨迹划分、第52—53章动作接口。本章不再堆一个新网络，而是学习判断训练数据与评测是否可信。

## 1. 一条记录要能还原一次决策

**数据卡（data card）**像数据的说明书，记录来源、采集方式、字段、划分、用途与限制。episode_id标记回合，时间戳标记顺序，任务文本说明目标；图像、状态、动作必须对应同一决策时刻。

本章附[教学数据卡](data-card.md)与自制小样本生成器。它不是公开真实机器人数据的下载样本，不能写成“已经检验Open X-Embodiment全部数据”。自制等价样本用于练习审计结构。

| 必查项 | 为什么重要 |
|---|---|
| 动作单位和模式 | 米、毫米、弧度、速度、位移不能混用 |
| 参考系和关节顺序 | 数字相同但轴或关节不同会执行另一动作 |
| 控制周期 | 同一速度保持多久决定移动距离 |
| 命令或测量 | 下达目标不等于实际到达位置 |
| 相机顺序、颜色、裁剪 | 模型的视觉约定可能依赖它们 |
| 夹爪定义 | 0是开还是闭，是否连续开度 |
| 时间与有效mask | 缺帧、填充、未来信息需要区分 |

## 2. 多份数据为什么不能直接拼接

若一份动作是工具系位移，另一份是基座系速度，需要参考系变换和时间尺度转换；缺少必要状态时不能无损转换。不同机械臂关节维数与可达空间不同，把缺失维简单补0不保证物理可行。

训练混合还会改变采样权重：长轨迹数据集按帧混合会占更多训练量；按回合或按任务平衡会得到不同分布。应报告每个来源、任务和本体的权重以及归一化统计计算范围。

[Open X-Embodiment项目](https://robotics-transformer-x.github.io/)提供跨机器人数据与模型研究案例；[BridgeData V2代码](https://github.com/rail-berkeley/bridge_data_v2)是公开示范学习参考。数据文件、代码和权重的许可不一定相同，使用具体资源前应阅读对应说明。本书没有批量下载这些数据或宣称全部字段已统一。

## 3. 拆分单位应匹配想证明的能力

按帧拆分只能检查近似重复样本；按轨迹拆分测试新回合；按对象或场景拆分测试新对象或场景；按任务或语言组合拆分检验更复杂泛化。不能把第52章的颜色位置组合测试直接称为“跨机器人迁移”。

重复视频、不同格式的同一轨迹、由测试任务生成的训练指令，都可能造成污染。外部预训练数据是否包含目标基准通常难完全确定，应说明已知情况与未知部分，不能把“不知道”写成“保证没有”。

## 4. 成功率要带分母

40回合成功35次，估计成功率 $\hat p=k/n=0.875$。**置信区间**像说明重复做同类抽样时估计会波动到什么程度，是由抽样规则构造、在重复实验中具有规定覆盖性质的区间。它不是“真实p有95%概率落在这次区间”的自动结论。

在简化独立二项假设下，Wilson区间为：

$$\mathrm{center}=\frac{\hat p+z^2/(2n)}{1+z^2/n},\quad
\mathrm{half}=\frac{z\sqrt{\hat p(1-\hat p)/n+z^2/(4n^2)}}{1+z^2/n}.$$

95%近似取z=1.96，区间center±half。即使40/40成功，下界也不是100%。如果同一场景重复许多次、同一物体高度相关，不能把所有帧当独立试验；应按场景等独立单位分组重采样。

本章复用第53章固定回合日志，报告每模型每组k/n和Wilson参考区间。它们只是该任务采样设计下的近似，不证明开放世界成功率。还按相同场景配对，分别在红/蓝两组内bootstrap重采样，估计流4步相对离散策略的成功率差，避免把两模型的场景差异当算法优势。

## 5. 运行数据审计与评测表

```bash
python chapters/53-vla-continuous-actions/examples/continuous.py
python chapters/54-robot-datasets-and-benchmarks/examples/audit_data.py
```

脚本生成三回合自制JSON，核对时间严格递增、动作维度、有限值、速度界限与固定周期；读取已有评测日志生成统计表。人工错误样例将单位改为毫米/秒，检查器明确拒绝。这里拒绝的是不符合当前schema的文件，而不是说毫米单位本身错误。

结果见[检查记录](validation.md)。当所有配对差都为0时，朴素bootstrap会给出[0,0]的退化区间，这只反映当前样本无法呈现差异，不证明总体差异严格为0。

完整评测还应报告任务定义、种子、训练预算、推理耗时、失败原因与资源。**离线动作误差**衡量对教师的局部拟合，**闭环成功率**衡量真实执行结果；二者都应在正确范围解释。

过关要求：能为陌生机器人数据写最小数据卡；指出合并前缺哪些转换信息；为泛化声明设计匹配的拆分；不给“100%成功”省略分母与条件。下一章检查模型与真实时间接口如何连接。
