## 世界模型先从最小预测器开始

**世界模型**像在脑中试着回答“如果我这样做，接下来会怎样”，在本书决策主线中指对环境变化及相关观测、奖励等进行预测的模型。它不必生成漂亮视频，也不必包含整个现实世界；必须说明建模范围和用途。

第42章用已知更新公式规划。本章把位置转移从数据学出来，暂不处理图片压缩与隐藏状态；第48章再加记忆与潜变量。先准确理解简单模型的输入输出，才能读懂大型系统。

## 1. 动作条件不能省略

对可观察状态s和动作a，确定性模型写成 $\hat s_{t+1}=f_\theta(s_t,a_t)$，概率模型写成 $p_\theta(s_{t+1}\mid s_t,a_t)$。观测预测可另写 $\hat o_{t+1}=g_\theta(\hat s_{t+1})$，奖励预测写 $\hat r_t=r_\theta(s_t,a_t,\hat s_{t+1})$。

同一位置向左和向右会有不同未来；不给动作的预测器只能平均训练数据中各种行动的后果，不能自然用于比较新的候选动作。即使视频看起来合理，也不能由此推出能回答任意动作的后果。

本章环境是第37章的二维理想速度系统，输入位置p与动作a，各2维，输出下一位置。目标g在回合内固定，既不影响动力学也不需要学习变化。奖励仍由已知距离公式算出，没有额外训练奖励网络。明确省略哪些模块，比把所有网络都统称为世界模型更有用。

## 2. 一步监督训练

保存转移 $(p_t,a_t,p_{t+1})$，先按轨迹拆分，再展开为训练行。训练目标为：

$$L=\frac1{2N}\sum_{i=1}^N\|f_\theta(p_i,a_i)-p_i'\|^2.$$

分母2对应两个坐标维，与PyTorch默认MSE一致。**残差预测**像先保留当前位置，再估计这一步改变多少；本章模型为 $f_\theta(p,a)=\operatorname{clip}(p+0.1\,h_\theta([p,a]),-1,1)$。

0.1是已知控制周期，边界裁剪也是已知先验结构；hθ仍需从数据学，不把真实a直接复制为结果。这样的结构降低学习难度，报告必须说明模型不是完全从零发现时间尺度和边界。

相比直接预测完整位置，小位移目标较容易与“保持不动”的基线比较。**持久性基线**是假设下一状态等于当前状态；动作幅度小时，它的一步MSE也可能很低，所以必须报告相对改善。

## 3. 一步准确不等于多步准确

一步测试每次提供真实p_t；多步**自由展开**从真实p₀开始，然后反复将自己的预测作为下一输入：

$$\hat p_{k+1}=f_\theta(\hat p_k,a_k).$$

未来动作可以是事先记录的动作序列，但未来真实位置不能喂给模型。否则每一步都被真值纠正，测到的是一步条件预测，而不是自由rollout。

误差会同时来自模型本身和输入逐渐偏离训练分布。并非每个系统误差都单调增加：稳定动力学或边界裁剪可能抑制某些误差，因此应画曲线或报告多个时域，不要把“必定指数爆炸”当普遍定律。

## 4. 动作覆盖与不确定性

训练动作各维均匀取[-0.3,0.3]米/秒，评测一组同范围动作，再评测[-0.5,0.5]。后一组包含超出训练支持的动作，称为**分布外（OOD）**情形；范围更大但仍有部分动作落在训练范围，需如实说明。

**环境随机性**像同样推法仍因无法控制的小扰动得到不同结果；**模型不确定性**像数据不足，不知道真实规律是什么。两者不同：更全面的数据可能减少后一种，未必消除前一种。确定性MSE模型常趋向条件均值，无法自动表达多种可能未来。

第37章环境完全确定，本章预测误差主要来自有限数据、函数拟合与分布偏移，不能把它称为已测得的真实物理随机性。第49章介绍多模型分歧作为一种不确定性线索，但它也不是可靠概率保证。

## 5. 运行与后续复用

```bash
python chapters/47-learned-dynamics/examples/dynamics.py
```

生成80训练、20验证、20测试轨迹，种子0—79、100—119、200—219；每条最多25步，若成功则提前结束。OOD轨迹用300—319及更大动作范围。每条动作随机数使用seed+1000，环境种子单独设置。

hθ为4→64→64→2的tanh隐藏MLP，种子7，Adam0.003、1000次更新、批128，每50步验证选模。报告测试一步MSE、不动基线，以及1/5/10/20步自由展开的末位置MSE与有效轨迹数。短于所需步数的回合不参与该时域评估，并报告数量，避免隐藏筛选。

权重保存供第49章规划、第50章想象训练使用。后续不能一边说“使用已学模型”，一边偷偷调用真实转移公式。模型只预测位置，完整观测里的目标由外部原样保留。

[检查记录](validation.md)给出结果。经典[World Models项目](https://worldmodels.github.io/)展示了表示、动态预测和控制的组合思路；本章尚未复现其图像压缩与循环预测架构。下一章逐步补上这些结构。

过关要求：区分策略 $o\to a$ 与模型 $(s,a)\to s'$；能保存动作对齐的轨迹；能分别实现teacher forcing式一步评测和自由展开；能写出动作覆盖范围；明确低预测误差是否真正帮助决策仍待第49章检验。
