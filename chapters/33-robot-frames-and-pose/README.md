## 从会回答到知道物体在哪里

前面模型能回答颜色，却还不能告诉机器人该朝哪里动。现在回到第10章的矩阵和几何。以后每次出现动作，必须同时问：谁在动、相对谁、用什么单位？

## 1. 先认识机器人的身体

**连杆**像手臂中一段不弯曲的骨头，是机器人中可近似看作刚体的部件。**关节**像肘部，规定相邻连杆允许的相对运动；常见转动关节绕轴旋转，移动关节沿轴滑动。**末端执行器**像手或夹子，是直接与任务对象交互的工具。工具尖端不一定和最后一个关节原点重合。

**自由度（DOF）**像需要几个独立旋钮才能确定姿势；准确地说，是描述系统局部构型需要的独立变量数。平面自由刚体有x、y和一个朝向共3个自由度；空间自由刚体有3个平移、3个旋转自由度。机械臂的关节数和目标任务需要的自由度不一定相等。

长度统一用米，角度在三角函数中用弧度。90度=π/2弧度，不能把90直接传入 `np.sin`。位置和角度也不能不加权直接混成同一种误差单位。

## 2. 同一个点，可以有不同坐标

**坐标系**像画在地图上的原点和方向箭头，是表示位置与方向的参考框架。世界系W固定在场景；基座系B固定在机器人底座；相机系C固定在相机；工具系E固定在工具。它们可以移动，且轴方向不能凭名字猜。

**位姿（pose）**就是“在哪里、朝哪边”，准确地说是一个刚体相对参考系的位置和朝向。只给(x,y,z)是位置，不是完整空间位姿。

本书采用列向量，$p^A$表示同一个点在A系中的坐标，$R_{AB}$将B系方向坐标转换到A系，$t_{AB}$是B系原点在A系的位置：

$$p^A=R_{AB}p^B+t_{AB}.$$

下标AB读作“从B到A”。这是一种约定，其他库可能不同；接入前必须核对。改变坐标描述不意味着物体真的移动。用同一个矩阵主动移动物体是另一种解释，不能在推导中悄悄混用。

## 3. 旋转矩阵从二维开始

平面逆时针旋转θ：

$$R(\theta)=\begin{bmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{bmatrix}.$$

当θ=π/2时，(1,0)变成(0,1)。三维绕z轴时保留z：

$$R_z(\theta)=\begin{bmatrix}\cos\theta&-\sin\theta&0\\\sin\theta&\cos\theta&0\\0&0&1\end{bmatrix}.$$

合法旋转满足 $R^TR=I$、$\det R=1$，所以逆为转置。第一条表示轴正交且长度不变；第二条排除镜像反射。浮点数检查用容差，不能要求所有元素精确相等。

例如相机C相对世界W绕z轴90度，原点在(1,2,0)米，点在相机系为(1,0,0)米，则世界坐标为(1,3,0)米。必须先旋转局部方向，再加上以世界系表示的平移。

## 4. 把旋转和平移装进同一矩阵

**齐次坐标**像给点额外带一个标记，让旋转和平移能用一次矩阵乘法完成；点写成 $\tilde p=[x,y,z,1]^T$，变换为：

$$T_{AB}=\begin{bmatrix}R_{AB}&t_{AB}\\0\ 0\ 0&1\end{bmatrix},\quad \tilde p^A=T_{AB}\tilde p^B.$$

方向向量或两点差没有原点位置，用末位0表示，因此平移对方向不生效。不要把速度方向当点，额外加一次平移。

若B到A、C到B已知，C到A为：

$$T_{AC}=T_{AB}T_{BC},\qquad
T_{BA}=T_{AB}^{-1}=\begin{bmatrix}R_{AB}^T&-R_{AB}^Tt_{AB}\\0\ 0\ 0&1\end{bmatrix}.$$

连续乘法从右侧先作用到点。逆变换的平移不是简单的负t，还要转换到新的参考系。一般 $T_1T_2\ne T_2T_1$，这正是机器人接口里常见的错误来源。

## 5. 姿态表示的选择

**欧拉角**像按约定顺序旋转三个旋钮，用三个依次绕轴的角表达朝向。必须注明轴顺序、固定轴还是随体轴。某些朝向下不同旋钮效果重合，参数表示出现奇异性；不能据此说真实刚体失去旋转自由度。

**单位四元数**可以理解为用四个互相关联的数稳定记录旋转；它不是四个自由度，因为有单位长度约束。作为自含选学，给定单位轴u和旋转角θ，可写：

$$q=(w,v),\quad w=\cos(\theta/2),\quad v=u\sin(\theta/2),\quad w^2+v^Tv=1.$$

q与−q表示同一旋转。常见库有wxyz和xyzw两种排列，必须明确。若想转换成矩阵，可用 $R=(w^2-v^Tv)I+2vv^T+2w[v]_\times$，其中 $[v]_\times$ 是使 $[v]_\times x=v\times x$ 的反对称矩阵；三维叉乘v×x得到垂直于两者的向量，其方向遵循右手规则。本章主线只要求会矩阵，不要求记住四元数公式。

## 6. 手算后再运行

```bash
python chapters/33-robot-frames-and-pose/examples/frames.py
```

程序检查旋转合法性、点的来回转换、坐标链组合以及点与方向的区别；数值见[检查记录](validation.md)。实验只演示几何，不代表真实相机已标定。实际标定误差、时间同步和噪声在第36章讲。

进一步参考[Modern Robotics齐次变换课程](https://modernrobotics.northwestern.edu/nu-gm-book-resource/3-3-1-homogeneous-transformation-matrices/)。先理解本章具体例子，再阅读其中更抽象的空间名称，不把术语记忆作为入门门槛。
