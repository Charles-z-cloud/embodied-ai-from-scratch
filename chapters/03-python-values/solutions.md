# 第 03 章参考答案与思路

[正文](README.md) · [练习](exercises.md) · [全书目录](../../README.md)

## 练习1

依次是字符串“42”、整数6、浮点数3.5、整数3。加号的作用与类型有关。

## 练习2

x最终为9，y为5。`y = x` 在当时让y绑定到值5，并没有建立“以后y永远跟随x”的公式。

## 练习3

位移为2−8＝−6厘米，平均速度为−6/3＝−2厘米/秒。负号说明相对于约定的向右正方向，净移动方向向左。

## 练习4

输入是字符串。先写 `duration_s = float(duration_text)`，再计算；输入必须为合法且非零的数值，本题还约定经过时间应大于0。

## 练习5

`color == "红色" and duration_s > 0`。它只产生真假值，不会自动改变后续执行步骤，需要下一章的条件分支。

## 练习6

净位移0，平均速度0厘米/秒；总路程为20厘米。它中途发生了移动。平均速度与平均速率不是同一个量，平均速率以总路程计算，本章练习主要使用平均速度。

## 练习7

浮点存储可能带来微小误差。可以使用 `abs((0.1 + 0.2) - 0.3) < 0.000001`。容差要对应问题的精度需求，不把此数值当作通用标准。
