## 练习1

不运行先判断：`"4" + "2"`、`4 + 2`、`7 / 2`、`7 // 2` 分别是什么？

## 练习2

逐行执行 `x = 3`、`x = x + 2`、`y = x`、`x = 9` 后，x与y各是多少？

## 练习3

方块从8厘米移到2厘米，用时3秒。手算位移与平均速度，再修改示例核对。解释负号。

## 练习4

`input` 得到的 `"3"` 为什么不能直接拿来做 `6.0 / duration_text`？写出转换。

## 练习5

写出判断“color是红色且duration_s大于0”的表达式。这个表达式本身会自动阻止程序执行除零吗？

## 练习6

一个方块先从0厘米到10厘米，再回到0厘米，共用5秒。平均速度是多少？这能说明总路程为0吗？

## 练习7

解释为什么不建议用 `0.1 + 0.2 == 0.3` 检查近似数值结果，并写一个容差比较。
