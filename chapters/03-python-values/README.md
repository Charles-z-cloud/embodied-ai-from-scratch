## 3.1 从输出一句话到计算一个结果

前置：[第02章](../02-computer-and-environment/README.md)。请先确保能够保存并运行 `.py` 文件。本章研究一维移动：方块沿桌面左右运动，我们规定向右为正方向，位置统一用厘米，时间用秒。

要回答“方块移动得有多快”，需要知道初始位置、结束位置和经过时间。我们先写固定数据的程序，再让使用者输入数据。数据记录与物理单位始终一起说明，这样后面接触机器人动作时，数字才有明确含义。

## 3.2 值、类型与变量

**值（value）**是程序处理的具体内容，例如数字2或文字“红色”。**类型（type）**说明这是哪一类内容，决定哪些操作有意义。

| 写法 | 类型 | 意思 |
| --- | --- | --- |
| `3` | int，整数 | 三个或编号三，具体由任务定义 |
| `3.5` | float，浮点数 | 用有限精度保存的数值 |
| `"3.5"` | str，字符串 | 三个文字字符组成的文本 |
| `True`、`False` | bool，布尔值 | 真、假两种逻辑结果 |

“浮点”现在可以理解为电脑保存小数的一种方式。它能表示很大的范围，但不是每一个十进制小数都能精确保存。

**变量（variable）**像贴在值上的标签，让我们以后能通过名称找到它。在 Python 中，更准确地说，变量名称绑定到一个对象；此刻先用数值与文字对象建立理解。

```python
start_cm = 2.0
end_cm = 8.0
print(start_cm)
```

最后输出 `2.0`。名称中的 `_cm` 是我们主动写出的单位提示，Python 不会自动检查厘米是否和米混用。

### 赋值不是数学中的等式

`=` 表示**赋值（assignment）**：先计算右边，再把左边名称绑定到结果。

```python
position_cm = 2.0
position_cm = position_cm + 1.0
print(position_cm)
```

第二行先取原来的2.0，加1.0得到3.0，再更新名称的绑定。输出3.0。数学中“一个数等于自己加一”不成立，但这里描述的是先后两次状态，不是要求两边永远相等。

给变量命名时使用字母、数字和下划线，不能以数字开头；本书采用有意义的小写英文名称。`start_cm` 和 `Start_cm` 是不同名称。名称必须先赋值再使用，`print` 等现有工具名也尽量不要拿来当自己的变量名。

## 3.3 表达式怎样计算

**表达式（expression）**是能被计算出一个值的写法，例如 `end_cm - start_cm`。Python 的常见算术运算包括：

| 符号 | 例子 | 结果 |
| --- | --- | --- |
| `+`、`-` | `8 - 2` | `6` |
| `*` | `3 * 2` | `6` |
| `/` | `7 / 2` | `3.5` |
| `//` | `7 // 2` | `3`，向下取整除法 |
| `%` | `7 % 2` | `1`，这里是除以2的余数 |
| `**` | `3 ** 2` | `9`，三的平方 |

`//` 是向负无穷取整，因此 `-3 // 2` 得到 `-2`，不应简单理解成“删去小数部分”。基础实验优先使用明确需要的运算，不用记忆复杂负数取余规则。

先乘除后加减；有歧义时用括号表达意图。例如 `(8 - 2) / 3` 得到2.0，而 `8 - 2 / 3` 是另一种计算。分母不能为0；一旦计算 `1 / 0`，程序会报告除零错误。

## 3.4 第一个有物理含义的公式

把起点位置记为 $x_{\mathrm{start}}$，终点位置记为 $x_{\mathrm{end}}$，位置变化记为 $\Delta x$。符号 $\Delta$ 在这里表示“变化量”，下标只是区分起点与终点的标签。

$$
\Delta x=x_{\mathrm{end}}-x_{\mathrm{start}}.
$$

2厘米移到8厘米，变化量就是6厘米。向右规定为正，因此这个结果为正；8厘米移到2厘米则是负6厘米。它描述的是起终点之差，并不一定等于整个过程中走过的总路程。

经过时间用 $\Delta t$ 表示，单位为秒，要求大于0。**平均速度**是位置变化除以经过时间：

$$
\bar v=\frac{\Delta x}{\Delta t}.
$$

上方横线表示这里取时间段内的平均值，不是在计算每一瞬间的速度。6厘米除以3秒，结果为每秒2厘米，写成2厘米/秒。若方块中途先来回运动再到终点，平均速度仍由起终点与总时间决定。

把公式直接对应到代码：

```python
start_cm = 2.0
end_cm = 8.0
duration_s = 3.0
displacement_cm = end_cm - start_cm
velocity_cm_s = displacement_cm / duration_s
print("位移（厘米）：", displacement_cm)
print("平均速度（厘米/秒）：", velocity_cm_s)
```

这里每个结果都保存在一个名称中，下一行才能继续使用。改变起点终点后重新运行，计算过程完全相同。这比每次手动修改最终答案更可靠。

## 3.5 文字、数字与显示

字符串由引号包围。`"2" + "3"` 得到文字 `"23"`，而 `2 + 3` 得到数字5。字符串的加号是连接文字，说明同一个符号对不同类型可以有不同含义。

```python
color = "红色"
print("目标颜色：", color)
print("2" + "3")
print(2 + 3)
```

`print` 可以用逗号接收多个内容，显示时默认用空格分隔。打印本身不会改变变量值。单引号和双引号都可以包住普通文字，但左右要配对；文字本身含双引号时，可以用单引号包住整段。

类型转换像把标签上的数字重新读成可计算的数。`float("2.5")` 得到数值2.5，`int("3")` 得到整数3，`str(3)` 得到文字“3”。`int(3.9)` 会得到3，不是四舍五入；`int("3.9")` 则会报错，因为这段文字不是整数格式。

想检查一个值的类型，可以用 `type`：`print(type("3"))` 显示 `<class 'str'>`。`class` 这个输出名称本章仅用来识别类型；如何自己定义类会在第07章系统介绍。

## 3.6 比较产生 True 或 False

计算“终点是否在起点右边”会得到真假，而不是距离：

```python
print(end_cm > start_cm)
print(color == "红色")
print(duration_s > 0)
```

本例三行都是 `True`。`==` 检查是否相等，`!=` 检查是否不等，此外还有 `<`、`<=`、`>`、`>=`。注意 `=` 是赋值，`==` 才是比较。

逻辑运算可以组合条件：`and` 要求两边都真；`or` 至少一边真；`not` 把真假翻转。

```python
is_target = color == "红色"
valid_time = duration_s > 0
print(is_target and valid_time)
```

现在我们只打印真假。如何根据真假选择执行不同代码，会在下一章学；本章的程序还不会自动因为 `valid_time` 为假就跳过除法。

## 3.7 输入让程序接收新数据

`input("请输入经过时间（秒）：")` 会显示提示并等待输入。你键入3并按回车，返回的仍然是字符串 `"3"`。需要先转换才能计算：

```python
duration_text = input("请输入正的经过时间（秒）：")
duration_s = float(duration_text)
print("平均速度（厘米/秒）：", 6.0 / duration_s)
```

这里要求使用者输入合法且大于0的数字。输入“很快”会转换失败，输入0会导致除零。这是当前简单版本的限制，下一章学习分支后先处理非正时间，第06章学习异常后再处理无法转换的文字。

这种安排让你每次只引入已经解释的语法，也清楚知道当前程序能处理什么。

## 3.8 为什么小数相等会让人意外

尝试打印 `0.1 + 0.2`，常见结果是 `0.30000000000000004`。原因是浮点数用有限的二进制位表示数，某些十进制小数只能近似保存。

测量和计算结果通常需要判断“足够接近”。例如：

```python
error = abs((0.1 + 0.2) - 0.3)
print(error < 0.000001)
```

`abs` 求绝对值，也就是离0多远，结果非负。这里容许差异小于百万分之一，输出True。这个容许范围应根据任务单位和所需精度选择，不是所有问题都统一使用它。

`round(value, 2)` 可以把数值按两位小数舍入，但不能把浮点存储变成任意精确的十进制运算。正文报告结果时既要考虑显示，也要考虑判断规则。

## 3.9 实验与排错

从本章目录运行 `python3 examples/motion.py`，会得到位移6.0、平均速度2.0以及两个真假检查。再运行 `python3 examples/interactive.py`，输入3，观察2.0厘米/秒的结果。

依赖仅为 Python 标准功能；使用第02章的独立环境解释器也可以。先把起点改为8、终点改为2，预测输出再运行。接着把起终点设为相同位置，想想平均速度0是否一定意味着中途没有动过。

常见报错：`NameError` 通常提示名称尚未定义或拼写不同；`TypeError` 可能意味着操作混用了不合适的类型；`ValueError` 可能意味着转换的文字不符合要求。`#` 后面直到行尾的内容是注释，用来解释代码，Python不执行它；放在引号内的 `#` 则只是字符串字符。
