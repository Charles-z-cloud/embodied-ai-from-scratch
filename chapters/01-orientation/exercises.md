# 第 01 章练习与自测

[回到本章正文](README.md) · [全书目录](../../README.md) · [参考答案](solutions.md)

这些练习只需要第01章的内容，无需编程、安装软件或查阅论文。先写下自己的回答，再对照答案。解释题允许不同表述，重点是逻辑是否说清楚。

## 练习1：把任务说清楚

桌面上有红色方块、绿色方块和蓝色目标区域。指令是“把红色方块移到蓝色区域”。

1. 写出本章为这次任务约定的成功条件。
2. 红色方块只有一个角碰到蓝线，是否已经完成？依据是什么？
3. 为什么不应该等机器人运行结束后，再临时决定什么叫成功？

## 练习2：画出反馈回路

用纸笔或文字画出包含以下内容的回路：桌面情况、相机图片、任务目标、选择动作、执行动作。

在图旁边回答：

1. 如果机器人执行动作后一直不再取得新图片，它可能遇到什么问题？
2. 它看到了新图片，但仍然无条件执行最开始的动作安排，这段执行有没有利用反馈？为什么？

## 练习3：根据输入输出辨认用途

下面是四个模块或系统的描述。说明它最接近本章哪类用途，并给出理由。一个完整系统可以同时包含多类模块。

| 编号 | 描述 |
| --- | --- |
| A | 接收桌面照片和“哪个是红色方块”，返回文字描述 |
| B | 接收桌面照片和任务指令，产生装置下一步要执行的移动指令 |
| C | 接收当前信息和一个候选动作，预测方块下一步可能到达的位置 |
| D | 相机、动作选择程序和机械装置一起工作，根据新观察不断调整，直到完成任务 |

再回答：仅凭上述简短描述，能否确认它采用了某一篇论文的模型结构？

## 练习4：把建议、指令、预测与结果分开

把下列四项分别归入“文字建议”“动作指令”“未来预测”“实际结果”：

1. 系统记录：“执行后，新照片显示方块移动了约1厘米。”
2. 一个助手说：“可以把方块向右移一点。”
3. 一个模型估计：“如果执行这次推动，方块可能向右移动约2厘米。”
4. 装置收到按接口约定填写的指令：“方向为右，请求移动2厘米。”

为什么第3项和第4项都提到2厘米，却仍不能证明方块实际移动了2厘米？

## 练习5：检查三个常见推断

分别判断下面的推断是否成立，并给出一个原因或反例。

1. “模型把照片解释得很清楚，所以它一定能把物体搬到正确位置。”
2. “一个方法属于 VLA，所以它一定显式调用了独立的世界模型。”
3. “生成的视频非常真实，所以模型一定可以准确预测我指定的推动动作。”

## 练习6：预测之后，还缺什么

桌上多了一个杯子。某个模型对两种候选动作给出预测：直接向右推可能碰到杯子；先绕开杯子再向右，可能到达目标区域。

1. 这体现了世界模型的什么用途？
2. 系统还需要完成哪些步骤，才能真正把方块移到目标区域？
3. 即使选择了预测更好的方案，执行之后为什么还要观察？

## 练习7：虚拟环境与真实环境

电脑里有一个虚拟机器人：它能取得虚拟相机画面，选择推动动作，环境根据动作更新方块位置，然后返回新画面。

1. 这个任务可以用于研究具身智能吗？说明依据。
2. 如果它在这个环境中完成了任务，能否直接宣布真实机器人也会成功？举两个可能的差异。
3. 如果另一个程序只对固定照片回答问题，我们能据此证明它已经完成了同样的交互任务吗？

## 练习8：把学到的内容迁移到新任务

新指令是：“把绿色方块移到黄色区域，红色方块保持原位。”

请写一段不超过200字的任务方案，包括：

- 怎样判断成功。
- 需要观察什么。
- VLM、VLA、世界模型分别可能提供什么帮助。
- 行动后应检查什么。

可以写出不同的方案，不要求必须使用全部三类模型。若选择不用某类模型，说明你的安排即可。

## 练习9：训练、推理与反馈

下面的行为分别涉及训练、推理、利用反馈中的哪一项？有些过程可以同时涉及多项。

1. 用许多带物体名称的图片调整模型的内部设置。
2. 把新照片交给已经训练过的模型，让它回答物体名称。
3. 机器人发现方块偏离目标，根据新图片重新选择动作，但没有更新模型的内部设置。

请说明：为什么“每次行动后都重新观察”不等于“每次行动后都重新训练模型”？

## 不看答案的过关自测

合上正文后，尝试完成以下检查：

- [ ] 我能独立画出反馈回路，并指出任务目标进入哪个环节。
- [ ] 我能解释练习3的四项描述，不把研究方向与单个模型混为一谈。
- [ ] 我能区分动作指令、未来预测和实际结果。
- [ ] 我能解释虚拟身体也能与环境交互，并说明仿真成功的局限。
- [ ] 我能为练习8的新任务写出至少一种合理方案。

全部能够解释，就达到了本章“理解用途”的目标。如果需要看答案才能说清某一点，先按答案中的回读提示补读，再用另一个物体或目标重新举例。
