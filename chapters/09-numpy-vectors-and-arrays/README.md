## 9.1 先问“一条记录有几个数”

前置：[第08章](../08-math-language-and-functions/README.md)。把一个位置写成2.0容易理解，但桌面位置通常要有横向和纵向两个数，多次测量又形成一张表。本章学习如何表示并批量计算这些数。

**标量（scalar）**是一个数；**向量（vector）**是有顺序的一组数；**矩阵（matrix）**是按行列组织的数。在机器学习代码里，**张量（tensor）**常指可有多个轴的数值数组；本书先采用这种操作层面的含义，数学和物理中的张量还有更完整的定义。

## 9.2 向量与矩阵的形状

一个位置向量可以写成：

$$
\mathbf x=\begin{bmatrix}2\\5\end{bmatrix}\in\mathbb R^2.
$$

粗体x提醒这是向量；两个分量可以分别表示水平与竖直位置，单位均为厘米。$\mathbb R^2$表示由两个实数组成的向量空间；此时理解为“有两个实数分量”即可。

三次测量按行放在一起：

$$
X=\begin{bmatrix}2&5\\3&5\\4&6\end{bmatrix}\in\mathbb R^{3\times2}.
$$

它有3行、2列，形状为$(3,2)$。**形状（shape）**是一组说明每个轴长度的数。这里轴0沿着三条记录，轴1沿着每条记录的两个分量。

轴的含义由我们约定，数组本身不会知道“第一列是x坐标”。先写清语义，再看形状；两个相同形状的数组也可能表示不同单位或顺序。

## 9.3 NumPy把这些数变成数组

**NumPy**是Python的数值计算库，提供同类数据的多维数组及批量运算。在学习环境中安装`python -m pip install numpy`，再导入：

```python
import numpy as np

X = np.array([[2, 5], [3, 5], [4, 6]], dtype=float)
print(X.shape)
print(X.ndim)
print(X.dtype)
```

`np`是人为约定的简称；`array`从列表创建数组；`dtype=float`要求浮点存储。shape为(3,2)，ndim为2，dtype说明具体数值类型。**轴的个数**与**每个轴的长度**不要混淆：二维数组也可能有一百万行。

创建全0数组可用`np.zeros((3,2))`，全1用`np.ones((3,2))`。`np.arange(4)`产生0、1、2、3；`np.linspace(0,1,5)`在0到1之间给出5个等间距点，默认包含两端。

整数数组与浮点数组的运算、赋值可能产生不同结果。例如向整数数组元素赋2.7可能截成2。测量与训练通常使用明确的浮点类型，不能只看打印出来“像数字”就忽略存储类型。

## 9.4 索引、转置与reshape

`X[1,0]`取第二行第一列，为3；`X[0]`取第一行，形状变为(2,)；`X[:,0]`取所有行的第一列。冒号含义延续列表切片，逗号分开不同轴的选择。

**转置（transpose）**交换矩阵的行和列，写$X^T$，代码为`X.T`。原先3×2变成2×3，原来的每一行成为一列。

`reshape`把相同数量的元素按新形状解释。例如`np.arange(6).reshape(2,3)`形成两行三列。它不是转置，也不是任意重排；默认按行顺序安排元素。元素总数必须不变，不能把6个数变成8个。

### 一维数组没有自动的“行列方向”

`v = np.array([2.,5.])`形状为(2,)，这是一个轴长度2的一维数组。`v.T`仍是(2,)。若明确要列向量，用`v.reshape(2,1)`；行向量用`v.reshape(1,2)`。

数学常把向量写成列，代码却经常保存成一维数组。比较两边时应主动说明形状，不能只看一个转置符号就认为代码也改变了方向。

## 9.5 逐元素运算与点积

相同形状的数组可以逐元素相加、相减或相乘：每个位置独立运算。`a * b`在NumPy中通常是逐元素乘法，不是矩阵乘法。

向量的**点积（dot product）**先把对应分量相乘，再加起来：

$$
\mathbf a^T\mathbf b=\sum_{i=1}^{d}a_i b_i.
$$

d是两个向量的共同分量数，i逐项编号。取a=(1,2,3)、b=(4,5,6)，点积为$1\times4+2\times5+3\times6=32$，是一个标量。

在一维NumPy数组上，`a @ b`或`np.dot(a,b)`得到这个数；`a * b`则得到(4,10,18)三个数。把“先相乘”误当成全部计算，会漏掉求和。

## 9.6 矩阵乘法逐格算

矩阵A形状$m\times k$，B形状$k\times n$时，它们的乘积C形状$m\times n$。中间的k必须一致：

$$
C_{ij}=\sum_{r=1}^{k}A_{ir}B_{rj}.
$$

i选择A的一行，j选择B的一列，r沿着这行和这一列逐项配对。每个输出格子都是一个点积。

例如：

$$
A=\begin{bmatrix}1&2&3\\4&5&6\end{bmatrix},\quad
B=\begin{bmatrix}1&0\\0&1\\1&1\end{bmatrix},\quad
AB=\begin{bmatrix}4&5\\10&11\end{bmatrix}.
$$

第一行第一列是$1\times1+2\times0+3\times1=4$，第二行第二列是$4\times0+5\times1+6\times1=11$。先推断2×3乘3×2应得到2×2，再检查数值。

代码写`A @ B`。反过来的`B @ A`是3×3，即使也能计算，形状和结果都不一样。矩阵乘法一般不能交换顺序。

## 9.7 沿一个轴汇总

`X.sum()`把全部元素加成一个数；`X.sum(axis=0)`沿行方向汇总，留下每一列的总和；`X.sum(axis=1)`沿列方向汇总，留下每一行的总和。

对前面的X，按轴0求和为(9,16)，按轴1求和为(7,8,10)。**归约（reduction）**就是把某些轴上的多个数汇总成较少的结果，例如求和与求平均。

`X.mean(axis=0)`计算两列各自的平均值；`keepdims=True`保留被汇总轴的长度为1，例如结果形状(1,2)。这样后面与原数组对齐时更容易看清意图。

不要靠“axis=0就是列”这种口号死记。轴0在本例对应记录编号；沿着它求和，就是把不同记录加起来，保留下每种特征。

## 9.8 广播：可以对齐，但也可能悄悄算错

如果每个二维位置都要加偏移(1,−1)，可以写：

```python
offset = np.array([1., -1.])
shifted = X + offset
```

**广播（broadcasting）**让某些不同形状在运算时按规则对齐。简单规则是从末尾轴开始比较：长度相同或其中一个为1就可以对齐；缺少的前方轴视作长度1。

本例(3,2)与(2,)对齐后，相同的两个偏移分别用于每一行。广播通常不需要真的复制三份偏移。

然而“没有报错”不代表意思正确。假设三个预测值形状(3,)，三个标签却是(3,1)，相减会得到(3,3)，形成两两组合，而不是预期的三个对应误差。

| 数组 | 形状 |
| --- | --- |
| 预测 | (3,) |
| 错误摆放的标签 | (3,1) |
| 相减结果 | (3,3) |

正确做法是根据语义统一形状，例如双方都是(3,)或双方都是(3,1)。随意reshape虽然可能消除报错，却可能把不同记录和特征混在一起，必须先确认排列含义。

## 9.9 视图、复制与条件筛选

NumPy基本切片经常返回原数组的**视图（view）**：像从同一块数据上开了一个窗口，修改窗口内容可能改到原数组。需要独立副本时使用`.copy()`。

```python
first_column = X[:, 0]
independent = X[:, 0].copy()
```

也可以用布尔条件选择数据，例如`X[X[:,0] > 2]`取横坐标大于2的行。这里比较先产生一串True/False，称为布尔掩码，随后决定保留哪些行。

组合数组条件使用`(条件1) & (条件2)`，并加括号；普通Python的and不是对每个数组元素逐项运算。初学时把每个条件先保存并打印，再组合，便于检查。
