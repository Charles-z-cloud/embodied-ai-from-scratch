## 在看分数前，先问要回答什么问题

第15、16章已经跑通训练与测试。本章要防止一个更隐蔽的问题：程序没写错，分数也很高，但实验没有回答真正关心的问题。

假设机器人要处理从未见过的新物体。我们把同一物体的不同照片随机分到训练集和测试集，模型可能记住物体上的划痕，在测试集里再次认出它。这证明了对“见过的物体的新照片”有能力，却未必证明对“全新物体”有效。划分方法必须跟目标问题对应。

## 1. 三份数据各做自己的工作

**验证集**像练习后的模拟考试，用于选择学习率、模型大小、训练轮数和阈值。**测试集**是方案固定后的最终考试，不能再根据其分数不断调整方案。

| 数据 | 可以用于什么 | 不能当作什么 |
|---|---|---|
| 训练集 | 拟合模型参数、计算预处理统计量 | 泛化能力的唯一证明 |
| 验证集 | 选择配置、停止时机、决策阈值 | 永远公正的最终分数 |
| 测试集 | 评估已确定的完整方案 | 反复调参的依据 |

**数据泄漏**可以先理解为考试答案或本不该提前知道的信息混进练习。准确地说，是训练或模型选择使用了评测时不应获得的信息，使评估偏离目标使用场景。泄漏不只包括复制标签，也包括同一对象跨集合、用未来信息预测过去、用全数据计算归一化参数等。

比如标准化：只用训练特征求均值 $\mu_{train}$ 和标准差 $\sigma_{train}$，随后所有集合都使用同一规则 $z=(x-\mu_{train})/\sigma_{train}$。不能给测试集单独重新算一套均值来偷偷适应它，除非任务协议明确允许并且评测正是在检验这种适应方法。[scikit-learn 常见错误](https://scikit-learn.org/stable/common_pitfalls.html)

## 2. 训练不够、模型太简单、记住噪声是不同问题

**欠拟合**像只学了一条过于粗糙的口诀，连练习题也做不好：训练与验证误差都偏高。原因可能是模型表达能力不足，也可能是优化没做好、输入没有有效信息。

**过拟合**像把练习题的特殊写法背下来：训练误差很低，但独立验证误差明显更高。数据少、模型自由度大、反复调参都可能增加这个风险。不能看到训练误差低就断言过拟合，要看与目标一致的独立评测。

**正则化**是在原目标里加入限制，避免参数为了贴合训练数据而过度扭曲。一种简单形式是L2惩罚：

$$
L_{total}(w)=L_{data}(w)+\lambda\|w\|_2^2,\qquad\lambda\ge0.
$$

$\lambda$ 控制对大权重的处罚强度，梯度增加 $2\lambda w$。它偏好较小权重，但不能修复标签错误或数据泄漏。截距是否也惩罚要事先说明；本书基础例子默认不惩罚截距。系数太大可能让模型欠拟合，应在验证集上选择。

**早停**像发现模拟考试不再进步后，保留表现最好的那次笔记。每隔固定步数评估验证损失，保存最佳参数；连续若干次没有改进就停止，这个允许等待次数叫patience。最终应恢复最佳参数，不一定是最后一次参数。判断标准、检查频率和等待次数都要提前确定，不能监视测试集来早停。

## 3. 混淆矩阵把“错在哪里”摊开

二分类把关心的类别叫正类，比如“有障碍”。**混淆矩阵**像一张答题统计表，把真实情况和预测情况交叉排列。本章规定行是真实类别、列是预测类别：

|  | 预测负类 | 预测正类 |
|---|---:|---:|
| 真实负类 | TN 真负 | FP 假正：误报 |
| 真实正类 | FN 假负：漏报 | TP 真正 |

这些英文缩写分别是 True Negative、False Positive、False Negative、True Positive。每个字母都在描述“预测是否正确”和“预测为哪类”。

$$
\mathrm{accuracy}=\frac{TP+TN}{TP+TN+FP+FN},
$$

$$
\mathrm{precision}=\frac{TP}{TP+FP},\qquad
\mathrm{recall}=\frac{TP}{TP+FN}.
$$

**精确率**precision问“说有的里面，多少真的有”；**召回率**recall问“真的有的里面，找到了多少”。名称相近，但分母不同。若没有预测正类，precision分母0，不能静默当成1；报告时应说明未定义或采用约定值。

例如TP=8、FP=2、FN=4、TN=86，总计100：准确率94%，精确率80%，召回率约66.7%。另一个数据集若1000条里仅10条正类，一律预测负类也有99%准确率，却漏掉全部正类。

需要一个同时考虑精确率和召回率的数时，可用 $F_1=2PR/(P+R)$，其中 $P,R$ 分别为precision与recall；它仍不能代替错误代价分析。多分类可以对每类做“一类对其他类”的统计；**宏平均**让各类别指标权重相同，**微平均**先汇总计数再计算，必须说清采用哪一种。

## 4. 校准：说九成把握，真的约九成正确吗

**概率校准**像检查一个人说“我有九成把握”是否靠谱。准确地说，模型给出相近置信概率的预测，其实际发生频率应与这个概率接近。

分类时常把最高类别概率作为置信度。可以把预测按置信度分箱，例如0.7到0.8一组，比较该组平均置信度与实际准确率；这是一种可靠性图的基础。也可以在二分类中直接比较正类概率与实际正类比例，须明确采用哪种定义。

假设10个预测都声称0.9，但只对6个，那么这一组平均置信度0.9、准确率0.6，表现为过度自信。只有10条时估计很不稳定，不能据此精确断言整体校准差值就是0.3。

常见汇总量ECE（Expected Calibration Error，期望校准误差）按各分箱样本数加权平均“置信度与准确率之差的绝对值”。它依赖分箱方式、样本数和所用置信定义，不能当万能结论。校准调整应使用专门验证数据，不能用测试答案修正后再宣称测试独立。[scikit-learn 概率校准说明](https://scikit-learn.org/stable/modules/calibration.html)

## 5. 划分单位决定分数的含义

如果实际问题是新物体，就按物体划分；问题是新场景，就按场景划分；要预测未来，就按时间保留后面的数据。训练、验证、测试之间还可能需要时间间隔，避免相邻帧几乎重复。

本章刻意构造一个“记物体编号”的分类器。60个物体，每个有10条观测，每个物体的类别随机为0或1。输入只有物体编号，没有可泛化的形状或颜色信息。分类器把训练里看到的编号与类别记在字典里；遇到新编号，预测训练集多数类。

这里无需提前学习新模型：字典就是第04章的查表工具。它不是拟合实际视觉规律，而是用于显示两种评测问题的差异。

- 随机按行拆分：大部分测试编号已在训练出现，查表可能得满分。
- 按编号拆分：测试物体完全没出现过，查表只能回退到多数类，表现接近猜测。

如果部署本就只处理固定一批已知编号，按行结果可能有其用途；问题出在把这个分数误称为“对新物体的泛化能力”，而不是一概把任何重复对象都叫非法。

## 6. 分数也有波动：重复实验与bootstrap

单次准确率只是某批数据上的观察。不同训练种子反映优化和采样的变化，不同测试对象反映评测样本的变化，应分别报告，不能把二者混成一个来源。

**bootstrap（自助重采样）**像从手里的对象卡片中有放回抽取一批、重新算分数，再重复很多次，用来估计评测波动。“有放回”允许同一对象被抽到多次。常见百分位区间取重复分数的2.5%和97.5%分位数，作为近似95%区间。

**分位数**可以先理解为把数从小到大排好后的一个位置，例如中位数是一半数据以下、一半以上的位置。这里用 `np.quantile` 计算分位数。

必须按合适的独立单位抽样：同一个物体的10帧高度相关，就应一起作为一个对象块重采样，不能把600帧当600个独立对象。本例每物体观测数相同，按物体平均和按行平均一致；观测数不等时要明确目标是“平均每个物体”还是“平均每帧”。

近似区间反映当前数据和方法假设下的不确定性，不保证覆盖未见的新分布，也不表示“真值有95%概率落在这一个已经算出的频率学区间里”。样本少、全对或全错时普通百分位bootstrap可能给出过窄甚至退化区间，必须报告样本量。方法接口可参考 [SciPy bootstrap 文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.bootstrap.html)，本章为理解原理直接用NumPy实现，未依赖SciPy。

## 7. 分布变化：换个环境，旧分数未必有效

**分布变化**就是部署时的例子不再按训练时那套规律出现。例如训练时光照明亮，部署时昏暗；训练都是塑料方块，部署出现透明玻璃；指令语法和物体组合也可能变化。

应事先把“同分布测试”和“新条件测试”分开报告。若只在结果不好以后不断改定义，评测会变成挑选有利答案。对具身任务，最终成功率还与连续动作的累积、接触和反馈有关，单张图片分类准确率不能替代整个任务的成功率。

运行本章实验：

```bash
python chapters/17-evaluation-and-generalization/examples/evaluation.py
```

它给出两种划分、对象交集、分数、按对象bootstrap区间和三个种子的对照；还打印手算混淆矩阵指标。不训练神经网络，不下载真实数据，目的是把评测陷阱单独暴露出来。

读代码时，`np.unique` 提取不重复编号，`np.isin` 判断每行编号是否属于指定集合，`np.flatnonzero` 把成立的位置转成索引，`np.intersect1d` 求两个编号集合的交集。`np.bincount` 数出各类别出现多少次，`argmax` 取最多的类别。这些操作让划分依据可以直接检查。

实际运行三个种子，按行划分均得100%，且全部测试物体编号都曾在训练出现；按对象划分得约55.6%—61.1%，测试均只有18个独立物体。按行bootstrap的区间退化为 `[1,1]`，只反映已观察到的查表结果全对，绝不能据此认为对所有新物体也有100%成功率。详细记录见[本章检查](validation.md)。

## 写下你的评测方案后再过关

用一小段文字交代：要泛化到谁、按什么单位划分、训练与验证各用来做什么、基线是什么、主指标和样本量是什么、哪种变化尚未覆盖。能写出这段，并解释为什么99%准确率可能很糟糕，就具备了进入神经网络章节所需的评测基础。
