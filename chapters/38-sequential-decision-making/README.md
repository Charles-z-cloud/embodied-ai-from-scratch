## 先把一轮交互说清楚

第37章已经有 `reset` 和 `step`。现在给这些对象准确名称。**智能体（agent）**像游戏中的玩家，是根据可获得的信息选择动作的决策系统；**环境**是接收动作并产生后续情况的系统。边界由建模选择决定，例如底层电机控制器可以归入环境，也可以归入智能体。

**状态s**像足够完整的游戏存档，是在选定模型中足以决定下一步分布的信息。**观测o**像玩家此刻能看见的画面，是系统提供给智能体的测量。状态可以包含速度、被遮挡位置，观测未必包含。第37章把位置和目标全部给出，在它的无惯性模型中足够；第35章点质量还需要速度，单给位置不够。

**动作a**是智能体可选择的输入；**奖励r**是任务定义的反馈分数；**策略π**像行动规则，准确地说是从可用信息到动作或动作概率分布的映射。策略不一定是神经网络，第37章手写控制也是策略。

## 1. 马尔可夫决策过程

**马尔可夫性质**像完整存档已经包含预测未来需要的信息，不必再翻全部录像；数学上表示在当前状态和动作已知时，更早历史不再改变下一状态的条件分布：

$$P(s_{t+1}\mid s_t,a_t,s_{t-1},a_{t-1},\ldots)=P(s_{t+1}\mid s_t,a_t).$$

**马尔可夫决策过程（MDP）**是用状态集合S、动作集合A、转移规律P、奖励规律和折扣等描述序列决策的模型。转移 $P(s'\mid s,a)$ 可以是概率分布，也可以是确定更新 $s'=f(s,a)$。它告诉我们“做了会怎样”；策略 $\pi(a\mid s)$ 告诉我们“选择做什么”。这一区分将贯穿世界模型与VLA。

本章用r_t表示执行a_t后收到的奖励，有些教材写r_{t+1}，只是索引约定，要保持一致。奖励可以取决于s、a、s'，不能默认只看当前图片。

## 2. 回报把多步联系起来

**回报（return）**像把一局游戏后面得到的分数按规则加总；**折扣因子γ**决定更远奖励在目标中的权重。有限长度轨迹的折扣回报为：

$$G_t=\sum_{k=0}^{T-t-1}\gamma^k r_{t+k}=r_t+\gamma G_{t+1},\qquad G_T=0.$$

γ通常在[0,1]；无限时域有界奖励时γ<1可让和收敛，有限时域可用γ=1。它不是学习率，也不必表示对真实时间的统一偏好：控制频率改变后，同样γ对应的时间尺度会变。

奖励序列[-1,-1,10]、γ=0.9，则G₂=10，G₁=8，G₀=6.2。若每步立刻选最大即时奖励，可能错过后面的大收益。**强化学习**是从交互反馈中调整策略以提高期望回报的一类学习问题；本章先描述问题，下一章再训练。

## 3. 看不全时，记忆为什么有用

**部分可观测**像只看见桌面一角，不能凭当前图确定所有相关情况；**POMDP**是在MDP之外用观测规律描述智能体只能看到部分信息的模型。常写 $o_t\sim O(\cdot\mid s_t)$，更一般观测也可依赖先前动作等。

最简单的反例：第一屏闪一下红灯或蓝灯，第二屏全部变黑；规则要求红灯后选左、蓝灯后选右。第二屏图像相同，但正确动作不同。只输入当前黑屏的确定策略不可能同时答对；记住第一屏就能区分。这与第25章序列记忆有直接联系。

历史 $h_t=(o_0,a_0,o_1,\ldots,o_t)$ 可以作为策略输入，或压缩成一个记忆变量。**信念状态（belief）**像为“真实情况可能是哪一种”保存概率表，准确地说是 $b_t(s)=P(s_t=s\mid h_t)$。简单确定提示任务只需要记一个颜色；一般问题需结合观测噪声与转移更新概率，不是保存最后一张图就足够。

## 4. 奖励不等于我们真正想要的结果

若任务希望“把物体放好”，只奖励“离目标近”，策略可能在目标附近但没有放稳；只奖励移动距离又可能学会乱跑。**奖励设计**是把任务偏好编码为数值目标，需要单独核查是否与成功标准一致。

**探索**像试走没走过的路以获得信息，是采集可能改善决策的数据的行为；它不是评价成功的指标。随机策略可作为探索方式，但不一定高效。新算法必须同时报告实际任务成功率，不能只看自己设计的奖励越来越大。

有限时间任务若规定“剩余一步”和“还剩一百步”应采取不同动作，剩余时间需要进入状态或相应的非平稳决策规则。第37章100步是采样上限；若将它改成任务本身的截止时间，就应重新明确状态和终止定义，不能只换一个标志。

## 5. 先手算，再做最小记忆实验

```bash
python chapters/38-sequential-decision-making/examples/decision.py
```

程序检查三个时刻的回报，并构造红蓝各50次的提示任务。当前黑屏策略固定选右；历史策略根据之前看到的提示选择。不是训练神经网络，而是一个可枚举的“不可能区分”的反例。记忆策略输入信息更多，结果不能表述成同输入下更强的网络。

[运行记录](validation.md)给出结果。经典系统参考为Sutton和Barto的[《Reinforcement Learning: An Introduction》第二版](https://mitpress.mit.edu/9780262039246/reinforcement-learning/)，后续可按MDP、价值学习、策略梯度顺序阅读，不必在初学时一次读完整本。
