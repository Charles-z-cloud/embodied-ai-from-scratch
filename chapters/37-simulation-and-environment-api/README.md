## 给后续算法一个共同任务

**仿真环境**像规则明确的小游戏，是用程序接收动作、更新状态并返回观测的系统。本章建立二维桌面上的点状移动物体，目标是到达指定位置。它没有碰撞动力学、抓取和接触，只用于学习交互接口，不能直接代表真实机械臂。

**回合（episode）**像从开局到结束的一局游戏，是从环境重置开始、直到规定结束条件满足的一段交互。**轨迹（trajectory）**是这一过程中按时间排列的观测、动作等记录；一条记录要能分清动作前后。

## 1. 先写清任务契约

桌面世界坐标范围[-1,1]×[-1,1]米，状态是当前位置p和目标g；观测向量为 `[px,py,gx,gy]`，float32，长度4。目标在一回合内固定。动作a是二维目标速度，单位米/秒，各分量限制[-0.5,0.5]，周期Δt=0.1秒。

$$p_{t+1}=\operatorname{clip}(p_t+\Delta t\,a_t,-1,1).$$

这里假设速度命令被瞬间准确跟踪，因此没有第35章的质量和惯性。这是明确的简化。以后比较算法时必须使用同一个更新规则，不能一边用力控制、一边用位置跳转却称为同一任务。

**奖励**像任务规则给每一步的分数，是环境返回的标量反馈；本章取 $r_t=-\|p_{t+1}-g\|_2$。尚未学习强化学习也能先理解这个返回值。距离小于0.05米算成功，最多100步。成功率是完成回合数比例，不等于累计奖励；两者都应记录。

## 2. Gymnasium接口逐项理解

[Gymnasium](https://gymnasium.farama.org/introduction/basic_usage/)为环境提供通用接口。先记住下面两行的结构：

```python
observation, info = env.reset(seed=7)
next_observation, reward, terminated, truncated, info = env.step(action)
```

`reset`设置初始状态并返回第一条观测；`step`执行一个动作，返回动作后的观测与反馈。`info`保存距离、成功等辅助信息，不能让策略偷偷读取不允许使用的真实信息。

**观测空间**像规定输入表格每列的范围与类型，是可返回观测的集合约束；**动作空间**类似地规定可提交的动作。代码使用 `spaces.Box` 表示连续数值区间，并明确shape与dtype。shape相同不保证物理含义相同，第36章的数据契约仍必需。

**终止（terminated）**表示任务本身结束，例如到达目标；**截断（truncated）**表示外部限制结束采样，例如时间预算用完。两者都会结束当前运行循环，但在第39章价值学习中，是否还应估计未来价值可能不同。本实现若末步同时达到目标和时间限制，优先报告成功终止，截断为False。

结束后必须reset，不可继续step。本章对NaN、无穷大和错误形状直接报错；有限但超范围的动作限幅到允许范围。记录原始命令时还应同时知道实际执行了哪个动作，不能混淆。

## 3. 种子和公平比较

`super().reset(seed=seed)`设置环境自己的随机数发生器。相同种子产生相同初始位置与目标，随机策略另用自己的种子。环境种子相同不代表策略随机序列也相同，要分别记录。

默认从[-0.8,0.8]生成起点与目标，保证初始距离>0.4米；也可用options指定二者。返回观测是拷贝，调用方修改数组不会悄悄改掉环境内部状态。重放保存的动作时，必须恢复同一起点目标和相同规则。

**渲染（render）**像把内部数字状态画出来，是生成供人或视觉模型查看的图像；它不同于物理状态更新。本章输出64×64 RGB数组，蓝色表示移动体、绿色表示目标。世界y向上，图片行号向下，绘制时明确翻转y。它是俯视符号图，不是假装用针孔相机得到的真实照片。

## 4. 两个无需学习的基线

**基线**像先给考试一个简单参照解法，是用于衡量新方法是否带来改善的比较对象。随机策略每步均匀抽动作；反馈策略取 $a=\operatorname{clip}(4(g-p),-0.5,0.5)$。

这个规则延续第35章“根据位置误差反馈”的思想，但输出速度而非力，所以不直接照搬PD增益。随着接近目标，命令变小；它使用完整位置观测，后续只看图像的策略得到的信息不同，报告必须标注。

```bash
python chapters/37-simulation-and-environment-api/examples/run_environment.py
```

两个策略在种子100—119的同一20个初始条件上各跑一回合，记录成功率、步数、回报和末距离。保存种子100的反馈轨迹为JSON，再新建环境按同种子重放全部动作，逐步比较观测。最终图保存为PNG，不要求图形界面。

代码文件 `tabletop_env.py`可被后续章节导入。外部项目[Farama-Foundation/Gymnasium](https://github.com/Farama-Foundation/Gymnasium)适合先读自定义环境教程；MuJoCo等物理仿真器还涉及接触、模型文件和求解器，属于在本章接口基础上的选学，未在本书此实验安装或运行。

## 5. 常见的接口错误

若动作正常却原地不动，先检查dtype是否把小数转成整数、Δt是否为0、是否每步都错误调用reset。若策略突然偏向错误方向，查y轴翻转是否只该发生在渲染而污染了物理状态。若成功后还收集大量样本，查结束条件。若测试成绩可疑地高，确认目标位置没有被当成不该提供给视觉策略的额外输入。

[检查记录](validation.md)报告实际运行版本和结果。过关要求：独立解释五个step返回值；能重放轨迹；能区分状态、观测和渲染图像；能明确任务只覆盖哪些物理现象。下一章用统一数学语言描述这种序列决策。
