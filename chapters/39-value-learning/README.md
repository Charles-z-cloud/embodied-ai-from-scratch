## 从回报到价值

先掌握第38章的状态、策略、转移和回报。**价值函数**像站在一个路口，估计“以后大概还能得到多少分”；准确地说，是给定状态或状态动作后，在指定策略下的期望回报：

$$V^\pi(s)=\mathbb E_\pi[G_t\mid s_t=s],\qquad
Q^\pi(s,a)=\mathbb E_\pi[G_t\mid s_t=s,a_t=a].$$

V问“在这里怎么样”，Q问“在这里先做这一步怎么样”。它们都包含后续回报，不是即时奖励。Q的第一个动作固定为a，后续才遵循π。不同策略通常有不同价值。

## 1. Bellman关系把长问题拆成一步

**Bellman方程**像把一条路的总成本拆成眼前一段与剩余路程，是利用 $G_t=r_t+\gamma G_{t+1}$ 建立的递归关系。对有限状态和动作、已知转移：

$$V^\pi(s)=\sum_a\pi(a\mid s)\sum_{s'}P(s'\mid s,a)[\bar r(s,a,s')+\gamma V^\pi(s')].$$

$\bar r$表示对应转移的期望奖励。内层对下一状态平均，外层对策略选择的动作平均；终止后的价值约定为0。最优价值把策略平均换成选最大：

$$V^*(s)=\max_a\sum_{s'}P(s'\mid s,a)[\bar r+\gamma V^*(s')].$$

**价值迭代**像反复用新的路况估计刷新地图，是从初始表V开始，对所有状态应用右侧更新直到变化足够小。已知环境模型时可以直接枚举下一状态，不需要先让智能体实际走遍每条路。有限折扣MDP在相应条件下有收敛保证；不能直接推广为任意深度网络训练保证。

## 2. 只拿到样本时怎么办

**Monte Carlo价值估计**像一局结束后，用实际总分更新对出发位置的评价，是使用完整采样回报作为目标。它等待回合结束，目标会受很多随机事件影响。

**时间差分（TD）**像走一步后，用“眼前得分＋对下个路口的新估计”更新看法，是使用其他价值估计构造训练目标：

$$\delta_t=r_t+\gamma V(s_{t+1})-V(s_t),\qquad V(s_t)\leftarrow V(s_t)+\alpha\delta_t.$$

α为学习率，δ为TD误差。这种用估计更新估计的方式叫**自举（bootstrapping）**，与第17章统计重采样的bootstrap不是同一个含义。终止时目标只剩r，下一状态价值不再加入。

## 3. Q-learning怎样学最优动作

**Q-learning**维护每个状态动作的价值表，用采样到的一步转移更新：

$$Q(s,a)\leftarrow Q(s,a)+\alpha\left[r+\gamma(1-d)\max_{a'}Q(s',a')-Q(s,a)\right].$$

d=1表示真实终止，否则为0。手算Q=2、r=1、下一状态最大Q=3、γ=0.9、α=0.1，目标3.7、误差1.7、更新结果2.17。

**ε-greedy探索**像大多数时候走目前最看好的路，小部分时候随机试路：概率ε随机选动作，其余取最大Q。**离策略（off-policy）**指学习目标策略可以不同于采集数据的行为策略；这里数据由ε-greedy产生，目标却用下一步最大Q。本章不要求未来真的随机到了那个最大动作才更新。

表格Q-learning的理论收敛还需要足够访问与适当学习率条件。本实验使用固定α和有限回合，展示算法，不拿理论保证替代实际结果。Q初始为0、每步奖励-1时是偏乐观的初始化，会影响早期探索。

## 4. 终止与截断影响目标

达到目标是真实终止，未来回报为0。若只是采样器到100步停止，而任务可以继续，通常仍应保留下一状态的价值估计；把 `terminated or truncated` 都乘进目标会产生系统性低估。若截止时间本身属于任务，则应把时间纳入状态并按真正终止处理。参考[Gymnasium时间上限说明](https://gymnasium.farama.org/tutorials/gymnasium_basics/handling_time_limits/)。

自动重置的批量环境可能返回下一回合首观测；更新上一回合的末步价值时，应使用正确的末观测。这个问题与公式对错不同，是数据接口问题。

## 5. 从表格到DQN，哪些困难增加了

**DQN**像把记不下的大表换成会概括规律的神经网络，用 $Q_\theta(s,a)$ 估计动作价值。离散动作时可一次输出所有动作的Q值，最小化预测与TD目标的误差。

**经验回放**把交互转移存入缓冲区并抽样训练，减轻连续轨迹样本强相关的问题并复用数据。**目标网络**使用一份更新较慢的参数副本计算TD目标，减少“正在追逐的目标同时剧烈移动”。训练目标应停止梯度，不能让两个分支互相移动来逃避误差。

神经网络会在不同状态之间共享参数，离策略、自举、函数近似结合后的稳定性不能照搬表格情况。本章只实现表格算法，不把DQN、连续控制或大规模游戏表现冒充为已验证结果。

```bash
python chapters/39-value-learning/examples/value_learning.py
```

价值迭代使用已知转移方程；Q-learning仅使用执行后的样本，种子7、3000回合、α=0.2、ε=0.2、每回合最多100步，从所有非终止合法格随机开始。训练时间上限是截断，因此末步仍自举。最终固定贪心Q策略，与价值迭代策略和随机策略在每个合法起点各5回合对照，报告成功率和路径步数。

已知模型规划器拥有更多信息，是可达性能参考，不是同数据条件的学习算法比较。程序同时报告Q表与最优Q表的最大差，说明“都能到终点”也不代表全部价值数字已经精确。
