## 本章接在哪里

先完成第28章训练，再读这里。你已经会训练“接着写什么”的模型，本章让同一模型按指定格式回答一个问题。仍然只使用CPU和自制语料；不把这个几十条示范的任务称为通用助手。

## 1. 四种容易混淆的操作

**预训练**像先读很多材料积累基本规律；准确地说，是在后续具体任务适配之前，通过某个训练目标学习模型参数。第28章的小语言建模训练在本章充当预训练，规模和知识覆盖远小于通用大模型。

**继续预训练**像换一本同领域材料继续练习阅读，一般仍沿用语言建模等目标。**监督微调（SFT）**像拿着“题目—标准答案”练习答题，是用有监督样本继续更新已有模型参数。两者区别主要在数据、目标及用途，不是是否调用另一种神秘优化器。

**提示词**是这一次递给模型的输入说明。改变提示词通常不会改变权重；微调会通过反向传播更新权重。提示词可以让模型使用已有能力，但不能保证它已掌握输入要求的技能。

**对话模板**像试卷上的“题目”和“答案”分隔线，是将角色、内容、边界编码成模型输入序列的规则。训练时和生成时必须使用同一规则。模型不会自动知道任意符号代表“现在开始回答”。

## 2. 只给答案打分，问题仍然可见

本章任务：给出“请把红色方块移到左边。”，在其后追加“方向：”，让模型输出“左”并停止。序列是：

```text
BOS 请把红色方块移到左边。方向： 左 EOS
       输入指令与提问前缀          监督答案
```

**标签掩码**像老师只给答题区评分，而允许学生阅读题目；准确地说，用一个0/1变量决定某位置的预测误差是否进入目标。设 $y_t$ 是位置t的目标词元、$m_t$ 表示是否为答案，目标为：

$$L=-\frac{\sum_t m_t\log p_\theta(y_t\mid y_{<t})}{\sum_t m_t}.$$

题目和PAD的标签置为PyTorch交叉熵约定的 `-100`，答案和EOS参与损失。不要把“题目不计损失”误写成“题目不允许注意”。因果掩码控制信息可见性，标签掩码控制打分位置，是两回事。训练时答案前一个位置预测答案；答案位置再预测EOS。

这里训练答案的前缀可以包含真实答案，即第25章的teacher forcing；最终评测必须只输入问题，让模型自己生成答案。把标准答案也送进去再报告正确率，不能证明会回答。

## 3. 改词表时权重怎样继承

第28章没有“方向：”中的全部字符。本实验明确追加新字符，保留旧ID不变，复制原有嵌入和词表输出头的旧行，新行随机初始化。两层Transformer和LayerNorm完整继承。固定正弦位置表扩到32位置，按公式重建，而不是从旧16位置缓冲区硬加载。

这是一个小规模适配流程。若只调用 `strict=False` 却不解释哪些参数没有加载，可能把随机网络当成预训练网络。实际框架还可能有嵌入与输出权重绑定，本章二者独立，必须分别复制。

## 4. 全量、冻结与LoRA

**冻结**像把某些旋钮锁住，只调其余部分；在训练中表示该参数不更新。全量微调更新所有可学习参数；冻结骨干只更新输出头或连接器，训练参数少，但可适配能力受到约束。

**LoRA**像给原来的大表格增加一个由两张窄表相乘得到的小修正；准确地说，冻结原矩阵 $W\in\mathbb R^{d_{out}\times d_{in}}$，学习低秩增量：

$$W'=W+\frac{\alpha}{r}BA,\qquad A\in\mathbb R^{r\times d_{in}},\ B\in\mathbb R^{d_{out}\times r}.$$

r是秩的上界，α控制缩放；列向量x的输出为 $Wx+(\alpha/r)B(Ax)$。训练新增参数 $r(d_{in}+d_{out})$ 个，原矩阵则有 $d_{in}d_{out}$ 个。输入输出维度都为32且r=4时，增量256个参数，原矩阵1024个，不计偏置。

常用初始化让A随机、B为零，因此开始时增量为零；两者都置零会使两边最初的梯度都为零。第一步B为零时A梯度可为零，B仍可获得非零梯度。低秩约束不意味着训练显存按同样比例下降，因为还要保留激活和冻结权重。可在合适条件下合并 $BA$ 到W用于推理。

本章训练实验采用全量微调，另做LoRA矩阵和参数量演示；**没有把全量微调的结果冒称为LoRA实验**。原始方法见[LoRA论文](https://arxiv.org/abs/2106.09685)。

## 5. 运行与评测协议

```bash
python chapters/28-tiny-language-model/examples/train_language.py
python chapters/29-adaptation-and-llm-evaluation/examples/finetune.py
```

第二条读取第一条的C=16权重和100/22/22句子划分，每条变成方向提取问题。固定种子7，Adam学习率0.001，300步，每步32条；每50步按验证答案交叉熵选择存档。测试只在最终选定权重上评测。记录原模型扩词表后、微调后的完整生成精确匹配率，要求方向字和EOS均正确，不能只挑第一个字符展示。

任务允许从指令直接读到方向，考查格式和抽取；不考查事实知识、图像理解或行动。未见整句共享模板，不等于未见自然语言表达。新模板、同义说法、否定句应另设测试，不能从当前正确率推断已经掌握。

**数据污染**像考前见过原题答案；准确地说，评测内容以直接或等价形式进入了训练或选模过程，导致评估不再代表所声称的泛化。第28章的预训练已见全部方向词，但未见本章测试原句，这要在报告里说明。

## 6. 指令遵循不等于事实正确

模型学会“按一句话回答”并不保证那句话真实。需要依问题分别评估格式、事实来源、任务成功、拒答或不确定性的表达。**偏好对齐**像让老师比较两个答案哪一个更合适，再利用这些偏好调整输出倾向；它是一类训练目标和流程，不自动提供可靠事实或物理知识。强化学习相关方法等第38—40章再学，这里不提前推公式。

本章必须会：画出输入、标签与掩码；说清冻结对象；手算LoRA形状；区分验证选模和最终测试；根据[运行记录](validation.md)判断结论适用范围。下一章先学图像怎样变成Transformer可读的序列，再连接视觉和语言。
