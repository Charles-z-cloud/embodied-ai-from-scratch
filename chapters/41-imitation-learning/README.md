## 用示范代替每次从头试错

**模仿学习**像先看老师怎样做，再学习相似行为，是利用专家行为数据学习策略的方法。专家可以是人、已有控制器或规划器，质量需要说明。**行为克隆（BC）**是其中最直接的方法：把观测当输入，把示范动作当标签，训练一个监督模型。

这与第40章REINFORCE不同：BC直接有“老师在这里做了什么”，不需要由回报给采样动作分配优劣。它也不会自动超越老师，尤其当示范覆盖有限、标签有偏或观测不充分时。

## 1. 从轨迹到训练样本

一条示范包含 $(o_0,a_0,o_1,a_1,\ldots)$。本章a_t必须与执行前观测o_t配对，不能错误配到执行后o_{t+1}，否则可能把动作结果泄漏到输入。

连续动作可最小化均方误差：

$$L_{BC}=\frac1{Nd_a}\sum_{i=1}^{N}\|\pi_\theta(o_i)-a_i^{expert}\|_2^2.$$

N为动作样本数，d_a为动作维度。离散动作则用分类交叉熵 $-\log\pi_\theta(a_i^{expert}\mid o_i)$。若连续输出按高斯分布建模，可以用负对数似然；固定方差时它与缩放的MSE相关。

相同观测如果存在两种合理动作，MSE倾向预测平均值。绕障碍可以从左或右走，两种动作平均可能直撞障碍。这个**多模态动作分布**是指条件动作有多个不同高概率区域，不是“同时有图像与文字”的多模态输入。第43—46章会补足生成动作所需基础。

## 2. 数据拆分和归一化必须先做对

一条轨迹中相邻帧非常相似，应先按回合划分训练、验证、测试，再切时间窗口。若任务包含多个场景或对象，还可能需要按场景、对象分组，第54章展开。

本章用第37章的理想速度控制环境，教师是位置误差反馈规则，延续第35章的控制思想，但不把力控制的增益原样当成速度控制。输入 `[px,py,gx,gy]`，输出二维速度米/秒。采集80条训练、20条验证、20条测试示范，分别用种子0—79、100—119、200—219。

输入标准化均值、标准差只由训练示范计算；动作本身已经处于[-0.5,0.5]，网络用0.5×tanh限制输出，不再另行标准化。输入统计和模型权重一起保存。时间窗口如果跨越回合边界，会把不同任务拼成一条历史，必须禁止。

## 3. 离线很准，为何执行仍会失败

**分布偏移**像学生走错一步后进入老师从未演示的路口，之后看到的情形与训练时不同。在BC中，训练观测由专家策略产生，实际观测由学习策略自己的过去动作产生；小误差会改变后续输入，产生误差累积。

因此必须评测两件事：在独立专家轨迹上预测动作的MSE，以及让学到策略实际控制环境的闭环成功率。前者低并不保证后者高。使用完整状态的简单任务可能两者都好，也不能据此否定真实复杂任务的分布偏移问题。

本章额外设置扰动评测：第3次决策前将环境位置加(0.35,-0.25)米并裁到桌面边界，再把新的真实观测交给策略。教师和BC在同种子条件下接受同样扰动；这是位置跳变，不是传感器噪声或持续外力。扰动可能恰巧让个别回合更容易，报告全部条件而非只挑困难示例。

## 4. DAgger：让老师给学生走到的地方标答案

**DAgger**像让学生先走，再请老师对学生实际到达的路口指出正确方向，是迭代收集学习策略访问状态的专家动作标签、加入数据集重新训练的方法。典型流程：初始示范训练BC → 用当前策略采样 → 在采样状态查询教师 → 聚合新旧数据 → 再训练。

它不同于只重复训练原始数据。教师要能在偏离轨迹的状态给出合理动作，查询也有成本；真实机器人还需要合适采集方式。方法依据见[DAgger原论文](https://proceedings.mlr.press/v15/ross11a.html)。本章只讲清机制，不把普通BC实验称为DAgger复现。

## 5. 实际训练与闭环评测

```bash
python chapters/41-imitation-learning/examples/bc.py
```

网络4→64→64→2，ReLU隐藏层、tanh动作头。种子7，Adam0.003、600次更新、批128；每50步按验证动作MSE选最佳权重。测试示范不参与训练与选模。CPU可运行，不需要真实机器人或外部数据下载。

程序保存每条轨迹的回合ID和样本数，输入归一化统计、权重、验证曲线、离线测试MSE、两个策略在20个测试起点的正常/扰动成功率。`load_policy`可供后续规划章节载入同一个策略，避免每章重新训练却不说明数据变化。

[检查记录](validation.md)报告真实结果。若全部成功，应进一步看完成步数或更严格条件；不能用“100%”代替任务范围。若失败，首先排查归一化恢复、动作与观测配对、坐标单位，随后才讨论模型容量。

经典项目[LeRobot](https://github.com/huggingface/lerobot)适合在掌握本章后阅读数据集与策略接口，再进入ACT等方法。本书此处没有安装整个LeRobot栈，也不声称复现公开机器人基准。

过关要求：能自己产生示范、按轨迹拆分、训练BC并闭环运行；能解释为何离线回归不是最终任务指标；能设计可暴露误差累积的测试。下一章将用已知动力学主动搜索未来动作，与直接输出动作的策略比较。
