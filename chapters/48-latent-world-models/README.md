## 观察不完整时，预测器需要记忆

第47章直接看见状态。实际相机可能被遮挡，单帧也不能给出速度。**潜在世界模型**像先把观察整理成内部笔记，再在笔记里推演未来，是在学习到的表示空间中描述环境变化的模型。潜变量不自动等于真实物理状态，是否保留控制所需信息必须检验。

基本模块为：观测编码e(o) → 内部状态更新 → 预测下一内部状态 → 解码观测、奖励等。图片重构好并不保证保留小而关键的接触信息；奖励与决策评测仍必要。

## 1. RNN回顾，再理解门

第25章RNN把当前输入与上一隐藏状态合并，得到新的记忆h。长序列中，普通递推可能难以保持有用信息。**门控**像在笔记本上决定哪些内容保留、哪些擦掉，是用0到1的可学习系数控制信息混合。

**GRU（门控循环单元）**是一种包含更新门和重置门的循环网络。用输入u、旧记忆h，简化写为：

$$z=\sigma(W_zu+U_zh+b_z),\qquad r=\sigma(W_ru+U_rh+b_r),$$
$$\tilde h=\tanh(W_hu+b_h+r\odot(U_hh+b'_h)),\qquad h'=(1-z)\odot\tilde h+z\odot h.$$

σ是sigmoid，⊙逐元素乘；这里z接近1时保留旧记忆。不同教材门命名与混合方向可能不同，必须核对。此候选状态形式采用与[PyTorch GRU](https://docs.pytorch.org/docs/2.14/generated/torch.nn.GRU.html)相容的重置位置，不能随意把r移入矩阵乘法里。

序列输入(B,T,d)，隐藏状态在每一步依赖过去，因此必须按顺序处理并在新回合重置。把一个回合的记忆带到无关测试回合会污染结果。为了简化，本章训练完整短序列，不做跨批隐状态延续。

## 2. RSSM组合确定记忆与随机状态

**循环状态空间模型（RSSM）**像同时保留一本连续更新的笔记，以及对当前未知情况的概率猜测，是将确定性递推状态与随机潜变量结合的序列模型。这里h_t是确定记忆、z_t是随机潜变量，与上一节GRU门的z不是同一对象。

给上一时刻状态及动作，先计算：

$$h_t=f(h_{t-1},z_{t-1},a_{t-1}),\qquad p_\theta(z_t\mid h_t).$$

后一个分布是**先验预测**，此刻还没有读取当前o_t。读到o_t后更新为近似后验 $q_\phi(z_t\mid h_t,e(o_t))$，再用(h_t,z_t)解码观测和奖励。先验与后验之差可以表示新观察带来的信息。

训练时后验看当前观测是允许的；想象未来时没有真实未来观测，只能沿先验展开。不能用后验偷偷编码未来图片，再把重构误差称为预测误差。模型为可用的动作条件记忆服务，不能只靠图片自编码器命名为RSSM。

## 3. 序列训练目标

一种基本形式在每时刻累加：

$$L=\sum_t\left[-\log p_\theta(o_t\mid h_t,z_t)-\log p_\theta(r_t\mid h_t,z_t)
+\beta D_{KL}(q_\phi(z_t\mid h_t,o_t)\|p_\theta(z_t\mid h_t))\right].$$

样本z_t来自后验；连续高斯潜变量可用第43章重参数化。β、奖励索引、终止预测、损失缩放与梯度截断在具体实现中各有约定；这是一条基础教学形式，不宣称等同所有Dreamer版本目标。

训练序列可利用当前真实观测修正状态，类似teacher forcing的思想；评测自由未来则只允许给定起点历史和候选动作。短重构误差与长自由预测误差应分开报告。有关确定与随机组件组合可参考[PlaNet论文](https://arxiv.org/abs/1811.04551)。

## 4. 先实现可读的确定性记忆模型

完整RSSM同时涉及多分布训练。本章先实现一个GRU预测器，隔离“记忆在遮挡时有何用”这个问题；**它没有随机潜变量、VAE或图像解码器，不是完整RSSM复现**。

一维移动物体有未知但回合内固定的漂移v，动作a_t是附加位移：$x_{t+1}=x_t+v+a_t$。初始x均匀在[-0.5,0.5]，v在[-0.05,0.05]，a在[-0.03,0.03]，单位米/步。第0—2步可见，第3—7步遮挡，第8—11步恢复可见。

输入为 `[可见时的位置，否则0；可见标志；本步动作]`，预测下一位置。标志区分“看不到”与“确实位于0”。仿真提供隐藏真值作为训练标签，但遮挡期间不进入模型输入。训练512条、验证128条、测试128条序列，种子100/101/102，模型初始化7。

比较单帧MLP与隐藏维32的GRU，均1000次Adam0.003更新、批32，每100步验证选模；参数量不同要记录。另设“保存最后位置并累加已知动作”的手写基线，它没有估计漂移v，因此仍可能积累误差。

```bash
python chapters/48-latent-world-models/examples/memory.py
```

报告总体与遮挡时刻下一位置MSE，以及“仅给前三步观测，此后全部遮挡”的额外自由观测条件。后一条件动作仍已知，但没有任何后续真实位置输入，不能把恢复可见后的纠正效果算成自由预测能力。

[检查记录](validation.md)给出结果。过关要求：按依赖顺序画出RSSM先验→读观测→后验；说清哪些变量是记忆、哪些是随机变量；指出本章代码相比完整RSSM少了什么。下一章回到第47章已学动力学，将它真正接入规划器。
