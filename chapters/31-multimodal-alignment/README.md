## 从各自表示到相互对应

第30章让图片变成向量，第24章让文字变成向量。现在的问题是：怎样让“红色圆形”的文字向量靠近红色圆形图片，而远离蓝色方形？先复习第10章余弦相似度和第16章交叉熵。

## 1. 两位翻译员，约定同一种向量语言

**双编码器**像两位翻译员，一个读图片，一个读文字，最后都写成同一种格式；准确地说，是两个分别处理不同输入的网络，输出到可比较的表示空间。图像编码器f、文本编码器g分别得到d维向量，并做长度归一化：

$$u_i=\frac{f(x_i)}{\|f(x_i)\|_2},\quad v_j=\frac{g(t_j)}{\|g(t_j)\|_2},\quad S_{ij}=u_i^Tv_j/\tau.$$

$x_i$为图像，$t_j$为描述，τ>0是温度。零向量要加很小的分母下界以免除零。归一化后点积是余弦相似度；它不是已经校准的“图片确实符合描述的概率”。

**正样本对**是数据中已知匹配的一图一文；**负样本对**是当前训练比较中被视为不匹配的组合。它们的正确性取决于配对规则，而不取决于在矩阵的哪个位置。本章排列令第i张图配第i条描述，因此对角线为正对。

## 2. 相似度矩阵怎样变成损失

**对比学习**像把正确配对拉近、错误配对推远，是利用样本关系学习表示的训练方法。B对数据构成B×B矩阵：行内选文字、列内选图片。双向目标为：

$$L_{I\to T}=-\frac1B\sum_i\log\frac{e^{S_{ii}}}{\sum_j e^{S_{ij}}},\qquad
L=\tfrac12(L_{I\to T}+L_{T\to I}).$$

第二项交换行列即可，也就是 `cross_entropy(S.T, arange(B))`。每个方向都是第16章的多分类交叉熵。τ越小，同样的相似度差会转成更尖锐的softmax；过小可能让错误负例的影响更强，并非越小越好。

手算：若两个样本的分数矩阵为 `[[ln3,0],[0,ln3]]`，每行正确配对概率3/4，每方向平均损失 $-\ln(3/4)\approx0.28768$，双向平均仍是这个数，不再乘2。

如果一个批次有两张都能描述为“红色横线”的图，普通对角线损失却把另一张当负例，就出现**假负例**：语义匹配但被错误排斥。可用多正例目标或设计不冲突的批次。本实验每批对每个训练颜色形状组合只取一张图，避免重复描述，不假装解决了开放世界中的所有语义歧义。

## 3. 检索和零样本分类

**检索**像从一堆卡片中找最匹配的一张；在这里是按相似度排序候选。给一张图，对九条颜色形状描述排序，第一名正确称为Recall@1命中。本章每张图只有一条语义标签，等价于这个候选表上的准确率。

**零样本分类**是没有使用目标分类任务的标注样本来训练该任务分类器，利用类别文字等现成信息完成预测。它不意味着模型从未见过相关词或图片，也不意味着不需要预训练。训练时见过某类别的图文配对，就不能把同类别的新图片结果笼统称为严格零样本学习。

本章专门留出两个颜色形状组合，训练只看其余七种，但所有颜色和形状单独都在训练出现。这检验组合泛化；候选描述由任务类别表定义，评测时不使用测试图片更新参数。

## 4. 自制小实验

```bash
python chapters/31-multimodal-alignment/examples/alignment.py
```

图片为12×12 RGB横线、竖线、十字，三种颜色，有位置与噪声变化。图像网络为展平→64维MLP→16维，文本网络使用六个已知概念词的嵌入，颜色和形状向量求和后线性投影到16维。它是受限词表文本编码器，不能理解任意中文句子。

七种训练组合每步各生成一图，Adam0.003、τ=0.1、600步、种子7。固定预算，不按测试调参。评测为新随机种子下每种组合40图，九条候选描述全部参与竞争；分别报告已见组合280图和未见组合80图，还计算训练组合新图片的准确率。数据由 `draw` 生成，后续章节可以复用这一小型图像生成器。

这种明确带组合结构的模型和数据，是理解损失的实验，不是CLIP规模训练。结果见[检查记录](validation.md)。若未见组合失败，检查是否把某种颜色绑定到某种形状、图像编码器是否靠背景猜标签、候选描述是否相互冲突，不应删除失败组合来提高成绩。

## 5. 提示词、噪声和能力边界

真实文本编码器可能对“红色方块”和“这是一张红色方块的照片”产生不同向量，因此类别提示模板也属于评测协议，应预先确定或只用验证集挑选。配错图片说明、网页水印和背景捷径都会改变学到的关系。检查更换背景、裁剪目标、交换描述后分数如何变化，通常比看一张漂亮相似度热图更有说服力。

双编码器会打分不等于会逐词回答；它没有本章之外的语言生成头。模型把两张图片排得近，也不意味着已学会三维位置或如何抓取。

## 经典项目与过关

[CLIP论文](https://arxiv.org/abs/2103.00020)是图文对比学习的代表；[OpenCLIP](https://github.com/mlfoundations/open_clip)提供开放实现。读源码时先找图文编码器、特征归一化、logit温度和损失，再看训练分布式细节。本章没有下载OpenCLIP权重或复现大规模训练。

过关要求：画出B×B矩阵；解释正例、假负例和温度；手算二样本损失；区分图文排序、分类和生成。下一章才把视觉信息送进能逐词生成答案的模型。
